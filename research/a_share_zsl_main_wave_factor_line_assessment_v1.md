## 1. 背景

交易者直觉："主升浪 = 动量 + 形态"。某对话会话据此构建了 15 个主升浪因子
（趋势状态/价格位置/突破/蓄势紧凑/量能确认/动量路径六类），并在一份验证中报告：
中期动量有效（IC≈+0.04）、VOL_TREND 与 PV_CORR_20 为"增量"、TIGHTNESS 方向反、
DIST_HIGH_250 无效、条件组合失败。

本次评估与复验回答两个问题：
1. 这些结论在仓库口径（`cn_data_2026` 后复权 + qlib csi1000 **历史成分** + ST/停牌/涨停过滤）
   下是否存活？
2. 主升浪因子与 Alpha158 的冗余度如何——"增量"主张是否成立？

---

## 2. 公式级冗余核对（评估阶段，alpha158_factor_guide.md）

| 主升浪因子 | Alpha158 对应 | 判定 |
|---|---|---|
| ABOVE_MA60 | MA60 = Mean(close,60)/close | 严格单调等价（重复） |
| VOL_RATIO | VMA20 = Mean(vol,20)/vol | 互为倒数（重复） |
| PV_CORR_20 | CORR20 = Corr(close, Log(vol+1), 20) | 近重复（仅 vol 对数变换） |
| MA_SPREAD / SLOPE_NORM | MA 族 / BETA 族 | 近亲 |
| MOM_20_5 | ROC20 | 高相关（无 skip-5） |
| SMOOTH_MOM / PULLBACK / TIGHTNESS | ROC/STD/MAX 组合 | 近亲 |
| DIST_HIGH_250 / UP_FROM_LOW_250 / BREAKOUT_120 | MAX/MIN 族（窗口上限 60） | **真差异化**（长窗口位置） |
| VOL_TREND | VMA 族（均为均量/当日量） | **真差异化** |

结论（评估阶段）：对话中"有效"的因子几乎都是 Alpha158 变体；唯一可能真有增量的
是 VOL_TREND 与长窗口位置因子。

## 3. 仓库复验（2026-08-11，脚本 v1）

### 3.1 口径

- 股票池：qlib csi1000 **历史成分**（2126 只，含被调出/退市，无幸存者偏差）
- 数据：`~/.qlib/qlib_data/cn_data_2026`（后复权），158.8 万行，1588 个交易日
- 窗口：检验 2022-01-01 ~ 2026-07-31，数据预热自 2020-01-01
- label：T+1 开盘成交口径 `Ref($open,-1)/Ref($close,-(h+1))-1`，h = 5/10/20
- 过滤：ST/*ST/退市整理（st_status_pit_v1 PIT 区间）+ 停牌 + 涨停信号日（主板 9.5%/

## 4. 与对话验证的对比

| 维度 | 对话结论 | 仓库复验 | 判定 |
|---|---|---|---|
| 中期动量有效 | ABOVE_MA60/MOM_20_5 IC≈+0.04 | ABOVE_MA60 +0.042、MOM_20_5 +0.034 | ✅ 方向与量级一致 |
| VOL_TREND/PV_CORR 为增量 | 是 | PV_CORR_20~CORR20 corr **+0.99**（duplicate）；VOL_TREND~VMA60 **-0.81**（near） | ❌ **增量主张不成立** |
| TIGHTNESS 方向反 | 是（-0.055） | -0.057（TIGHTNESS_20） | ✅ 一致 |
| DIST_HIGH_250 无效 | IC≈0.005 | +0.006（ICIR 0.03） | ✅ 一致 |
| 2026 年趋势类衰减 | 有 | ABOVE_MA60 +0.002、SMOOTH_MOM +0.001、DIST_HIGH_250 -0.037、BREAKOUT_120 -0.037 | ✅ 一致 |

**复验新增发现（对话未提及）**：
1. **UP_FROM_LOW_250（距 250 日低点涨幅）IC +0.0429，5 年全为正**，且与 Alpha158
   MIN 族相关仅 -0.69（distinct）——**15 个因子里唯一"真差异化 + 有效 + 分年度稳定"**。
2. PV_CORR_20 虽被判定 duplicate，但其分年度最稳（2022-2026 全为正，2026 仍 +0.038），
   ICIR 0.37 为全表最高——"稳"是真的，但作为 Alpha158 CORR 的变体无独立增量价值。
3. TIGHTNESS_20 负 IC 与 STD20 相关 +0.94，本质是 A 股"高波动低预期收益"（彩票偏好/
   特质波动异象）的已知结论，非新发现。

## 5. 最终结论

### 存活（保留资产）
- **UP_FROM_LOW_250**：唯一通过"差异化 + 有效 + 稳定"三重检查的因子，值得单独深验
  （长窗口/中性化/进 LightGBM 增量测试）。

### 死亡（不再投入，结论归档）
- 紧凑蓄势（TIGHTNESS）——方向反，且是已知波动异象；
- 突破前高（BREAKOUT_120/DIST_HIGH_250）——IC 弱且 2026 转负；
- FIP_60——无效且符号不稳；
- 条件组合（形态内挑动量）——对话验证已失败，本复验未复现，判定不投入。

### 冗余（对 Alpha158 无增量，勿进模型）
- ABOVE_MA60/MA_SPREAD/VOL_RATIO/PV_CORR_20/SMOOTH_MOM/PULLBACK_20 等为 duplicate
  （|corr|>0.95），SLOPE_NORM/MOM_20_5/VOL_TREND/TIGHTNESS_20 为 near_duplicate。

### 门槛评估
- 全部 15 因子 ICIR 最高 0.37（PV_CORR_20），**低于 `metrics_judgment_standard.md`
  的 0.5 门槛**；按仓库标准无一合格，需组合/中性化后再评。
- 2026 年趋势/位置类全面衰减，与 DEV_LOG"2021 后价量 alpha 衰减"同向，非孤立现象。

### 收尾：趋势持续性检验（2026-08-11，主升浪线终章）

承接 §5 的框架判断（"主升浪若可交易，必是趋势持续性识别而非形态识别"），
另行立项的时序结构检验已完成并归档：

- 协议：`research/protocols/a_share_trend_persistence_protocol_v1.md`（状态
  `executed_supported`）；脚本与产物：`scripts/analyze_a_share_trend_persistence_v1.py`、
  `output/analysis_static/a_share_trend_persistence_v1/`
- 结果（沪深普通 A 股母池 5542 只，2022-2026，h=5）：T1 状态价差年化 +0.166
  （t=4.99，2022-2025 四年全正）；T3 控制截面动量后状态增量 +0.045（t=3.43），
  非"截面动量换皮"；csi1000 辅助层同向。排序层质量弱（ICIR 0.23），2026 震荡期
  信号翻转（4/5/6 月为负）。
- 定性：趋势状态（自身收益符号）的持续性是**系统性暴露**（市场/行业状态延续），
  非个股选股 alpha；已按协议定位为**价值质量策略的趋势确认/剔除层候选**，不单飞。

**主升浪线最终状态：已收口**。横截面形态变体全部判死；时序趋势状态存活但仅获
"候选叠加层"资格，激活条件为主线（价值质量月频）验收通过后另行立项。此前的
UP_FROM_LOW_250 不再单独深验（其信息已含于本线收尾结论）。

## 6. 方法要点（脚本 v1 已知约束）

- FIP_60 不能用 qlib 表达式可靠实现（`Count` 对布尔比较语义有坑：`Greater($x,0)`
  返回浮点 max(x,0)，上涨日占比高导致恒 0），已改为逐股 pandas rolling 计算。
- 复验未复现对话的"条件组合检验"（形态子集内 IC），如需可扩展。
- 未做多重检验校正（15 因子 × 5 年），结论以"冗余 + 分年度稳定性"为主判断。
