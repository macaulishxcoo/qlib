# 日频 A 股量化研究计划（沪深主板）

> 目标：在**扣除全部交易成本后**，相对基准实现 **≥10% 年化超额收益**的日频策略，
> 初始资金 ¥500,000，标的限定为沪深主板。

---

## 1. 成功的定义（我来定义，比"超额 10%"更严格）

单一数字（超额 10%）很容易被"过拟合 + 单一路径运气"骗过去。所以我把验收标准写成
**一组必须同时满足的门槛**，全部在**样本外滚动验证**上计算：

### 1.1 硬性门槛（必须全部通过）

| 维度 | 门槛 | 说明 |
| --- | --- | --- |
| 年化超额收益（净） | **≥ 10%** | 相对 沪深300全收益；滚动窗口样本外合计 |
| 净信息比率 IR | **≥ 0.8** | 超额收益 / 超额波动，年化 |
| 超额最大回撤 | **≤ 15%** | 绝对净值最大回撤 ≤ 25%，两者取严 |
| 滚动 12 个月胜率 | **≥ 70%** 的窗口净超额 > 0 | 防止"全靠 2015 或 2020 一年" |
| t 统计量 | **≥ 2.0** | 对月度净超额序列 |
| 容量约束 | 单票下单金额 ≤ 该票 20 日均成交额的 **1%** | 50 万资金下意味着成分股 ADV ≥ ¥500 万 |
| 换手预算 | 单边年化换手 ≤ **25 倍**名义本金 | 约等于平均持仓 ≥10 个交易日满仓 |

### 1.2 成本模型（我会用这个，而不是默认参数）

A 股主板当前真实成本（2025 口径）：

| 项目 | 费率 | 备注 |
| --- | --- | --- |
| 佣金 | 0.025%（双边），单笔最低 ¥5 | 万 2.5 是当前主流券商量化通道费率 |
| 印花税 | **0.05%（仅卖出）** | 2023-08-28 起由 0.1% 减半 |
| 过户费 | 0.001%（双边） | 沪深两市统一 |
| 滑点 | 0.05% – 0.10%（单边） | 主板流动性好，按半个价差 + 冲击估计 |

**基准单边成本取 0.15%**（往返 0.30%）。所有结果必须做 **1× / 2× / 3× 成本压力测试**，
只有 2× 成本下仍满足 1.1 的策略才算通过。

> 关键推论：**换手是这类策略的头号杀手**。若日均单边换手 40%（日频 TopK 常见），
> 仅成本就是 0.4 × 0.30% × 244 ≈ **29%/年**。这几乎可以单独解释"为什么以前的实验都不行"。
> 所以本计划把**持仓周期定在 5–10 日**，并把换手当作一等约束。

### 1.2.1 50 万资金特有的成本陷阱：¥5 最低佣金

绝大多数回测（包括 qlib 默认设置）都**没有建模单笔最低佣金 ¥5**。在 50 万资金下这不是
小事，而是会改变结论的量级：

- 佣金费率 0.025% 时，**¥5 的地板在单笔成交额低于 ¥20,000 时开始生效**
  （5 ÷ 0.00025 = 20,000）。
- 50 万 ÷ 50 只 = 单只仓位 ¥10,000 → **每次调仓都必然触发地板**，
  实际佣金率被抬到 0.05%–0.5% 不等（取决于单笔金额）。
- 单笔 ¥1,000 的调仓 → 佣金 ¥5 = **0.5%**，是名义费率的 **20 倍**。

**直接结论（会写进组合构建约束）：**

| 持仓只数 | 单只仓位 | 典型调仓单（30% 仓位） | 实际佣金率 |
| --- | --- | --- | --- |
| 100 只 | ¥5,000 | ¥1,500 | 0.33% |
| 50 只 | ¥10,000 | ¥3,000 | 0.17% |
| 25 只 | ¥20,000 | ¥6,000 | 0.083% |
| 10 只 | ¥50,000 | ¥15,000 | 0.033% |

所以 50 万资金下，**"持仓 60–100 只"这个教科书默认值本身就是成本灾难**。
本计划的默认区间改为 **20–40 只**，并且回测引擎必须精确建模 ¥5 地板
（已实现在 `cnquant/backtest.py::_affordable_shares` 与 `_trade_cost`）。

> 补充说明：地板只影响佣金这一项。印花税（0.05% 卖出）、过户费、滑点仍按比例。
> 25 倍年化单边换手下，地板带来的额外成本约 **0.5%–1.5%/年** —— 重要，但不是唯一杀手；
> 真正的杀手仍是**总换手 × 单边成本**。


### 1.3 交易规则假设（必须建模，否则回测全是假的）

- **T+1**：当日买入不可当日卖出。
- **涨跌停**：主板 ±10%（ST ±5%）。开盘即涨停 → 不能买入；跌停 → 不能卖出。
  回测中这些单子要**顺延或丢弃**，不能假设成交。
- **停牌**：停牌期间不可交易，复牌后按实际价格处理；停牌票不能进入新开仓。
- **ST / \*ST**：默认剔除（可通过配置开启对照）。
- **新股**：上市未满 60 个交易日的剔除。
- **复权**：必须用后复权价做收益计算，用**未复权价**判断涨跌停与成交。
- **基准**：沪深300全收益指数（000300 的收益版本）。备选：中证500（若策略偏小盘）。

### 1.4 反面标准：什么情况下我判定"此路不通"

- 只在成本 <0.1% 时才成立；
- 只在某一年（2015/2020）贡献全部收益；
- 需要持仓 >200 只或日均换手 >60% 才能达标；
- 因子 IC 显著但**扣成本后净超额 < 5%**（说明信号太短周期，属于"正确但不可交易"）；
- 样本外与样本内差一个数量级（过拟合）。

## 2. 为什么之前的实验大概率失败（待验证的假设）

在写任何新因子之前，先逐条验证这些假设。**其中 H1 和 H4 是最可能的元凶。**

| # | 假设 | 如何验证 |
| --- | --- | --- |
| **H1** | **数据质量**：qlib 社区版 CN 数据（源自 Yahoo/新浪）存在幸存者偏差（退市股缺失）、复权因子不一致、停牌/ST 标注缺失、换手率口径错误 | 与 baostock 逐日比对 OHLCV + 复权因子；统计股票池里退市股数量（应为 0 → 说明有偏差） |
| **H2** | **标签/周期错配**：Alpha158 默认标签是 `Ref($close,-2)/Ref($close,-1)-1`（1 日前瞻），这是最拥挤、最被成本吃掉的方向 | 检查实验配置里的 label 定义 |
| **H3** | **没有风险中性化**：树的输出直接当分数用，隐含小市值/高波动/低流动性暴露，样本内好看、样本外崩 | 对预测值做行业/市值/波动回归，看 R² 与残差 IC |
| **H4** | **组合构建忽略成本**：`TopkDropout(n_drop=5, topk=50)` 每日调仓 → 单边换手 30–60%/日 → 成本 20–40%/年 | 用同一份预测值，只改组合构建 + 成本模型，看净收益变化 |
| **H5** | **Alpha158 因子本身衰减**：150+ 个价量技术因子高度冗余，2018 年后被量化资金拥挤化 | 分年度看 Alpha158 原始因子的 IC 半衰期 |
| **H6** | **评估方法**：单一 train/test 切分、以 IC 而非净值作为目标、没有 regime 分析 | 检查实验记录 |

> 重要立场（与用户一致）：**方法（因子 + 机器学习 + 回测）本身没有错**，
> 错的多半是数据、周期、成本与组合构建这些"工程细节"。所以本计划**先修地基，再谈因子**。

## 3. 研究路线（六个阶段，严格按序）

### Phase A — 数据地基（最高优先级，一切的前提）

产出：一套**干净、可复现、无幸存者偏差**的日频面板。

- 主数据源：**baostock**（免费、无需 token、自带复权因子、`isST` 标记、停牌标记、行业分类）。
- 补充源：**akshare**（另类数据）、**tushare**（若用户有 token，用于交叉校验）。
- 交叉校验：把 qlib 社区数据作为第三方对照，量化差异。
- 必须包含退市股（akshare 可取退市清单），否则横截面收益被系统性高估。
- 输出：`parquet` 面板（date × instrument），含 `open/high/low/close/volume/amount/adj_factor/
  turnover/pct_chg/is_st/is_suspended/limit_up/limit_down/industry/float_mcap/total_mcap/list_date`。
- **验收**：随机抽 20 只票、5 个日期，手工与东方财富页面核对；统计缺失率 < 0.5%。

### Phase B — 干净的模拟器

产出：向量化回测引擎，成本/规则完全可控。

- 事件顺序：`T 日收盘生成信号 → T+1 开盘（或 VWAP）成交`，严格无前视。
- 未成交处理：涨跌停/停牌导致的不成交要显式记录，并对净值产生真实影响。
- 输出：净值、超额净值、换手、成本拆解、分年度/分月归因、持仓集中度。
- **自检**：用"随机打分"跑一遍，净超额应≈ −成本；用"完美未来收益"跑一遍，应接近理论上限。
  这两条就能证伪大多数引擎 bug。

### Phase C — 因子研究（5 日 / 10 日 horizon）

先建基线因子库（对齐 Barra / 学术因子），再上差异化因子。

**C1 基线因子（必须全部建出来，用于对照与中性化）**

- 规模：总市值、流通市值
- 价值：BP、EP、SP、CFP、股息率
- 质量：ROE、ROA、毛利率、应计、资产增速、杠杆
- 动量：12-1 动量、1 个月反转
- 波动：1/3 月已实现波动、特质波动、beta
- 流动性：1/3 月换手率、Amihud 非流动性、换手率波动
- 情绪：MAX（一个月最大单日收益）、偏度

**C2 差异化因子（本项目的主要增量，主板散户结构下更有效、更不拥挤）**

- **隔夜 / 日内收益分解**：隔夜跳空累计 vs 日内收益累计的背离（Alpha158 基本没覆盖）
- **量价背离**：量价相关性、价格延迟（Dimson R²，用滞后市场收益解释个股）
- **涨跌停基因**：过去 20 日涨停次数/连续涨停/打开涨停次数
- **股东户数变化**（季度）：户数下降 = 筹码集中，A 股有据可查的强异象
- **业绩预告 / 快报惊喜**：预告类型与修正方向（A 股 PEAD 的核心载体）
- **机构调研次数**（akshare）：调研密度是关注度与基本面的代理
- **融资融券余额变化**：杠杆资金流向
- **龙虎榜**：上榜次数与席位结构
- **限售解禁**：未来解禁压力（负向）
- **回购 / 增持 / 减持公告**：内部人行为
- **大宗交易折价率**
- **分析师一致预期修正 / 评级调整**

**C3 因子的评估口径（每个因子都要产出这张表）**

- Rank IC 均值、ICIR、IC 衰减曲线（1/5/10/20 日）
- 分年度 IC 稳定性（防止只在某一年有效）
- 分组单调性（10 组，多空、多头超额）
- 换手率与**扣成本后的多头超额**
- 与基线因子的相关性矩阵（找真正正交的增量）
- 行业/市值中性化前后对比

### Phase D — 信号合成

- 起点：等权 / IC 加权合成（先不碰复杂模型）。
- 再到 LightGBM，但必须用**净化 +  embargo 的滚动交叉验证**（purged K-fold），标签用
  **5 日 / 10 日前瞻、行业市值中性化后**的收益。
- 核心动作：**对最终预测值做行业中性 + 市值中性 + beta 中性**，输出残差分数。
- 反过拟合纪律：记录试过的因子数量与变体数，用 deflated Sharpe 的思想打折。

### Phase E — 组合构建（这里往往比因子更能决定成败）

- 多头组合 **20–40 只**（不是教科书式的 60–100 只，原因见 §1.2.1 的 ¥5 佣金地板）。
- 行业上限、单票权重上限。
- **缓冲带法（band rebalancing）**：进入前 N 名才买，跌出前 `N × 2` 名才卖。
  这是最简单、最有效的降换手手段，几乎不损失信号质量。
  ⚠️ **陷阱**：退出窗口必须显著小于候选池。若候选池只有 50 只而
  `N=30, exit_multiple=2`（退出窗口 60），所有持仓永远"还在窗口内"，
  组合会**永久冻结** —— 表现为一个换手极低的"优秀"策略，实际是 bug。
  已在 `cnquant/portfolio.py::_select` 里加了钳制（退出窗口 ≤ 候选池的 60%）。
- 权重方案：等权 / 打分加权 / 波动率倒数加权。
- **风险中性化**：先按行业做固定效应去均值，再对（同样行业去均值后的）对数市值回归取残差
  （Frisch–Waugh–Lovell，两步等价于联合回归）。避免组合变成伪装的小市值或行业押注。
- 无交易带（no-trade band）：目标权重偏离小于阈值就不动。
- 目标：把单边年化换手压到 **≤25 倍**。

### Phase F — 滚动验证与压力测试

- Walk-forward：滚动 3 年训练 / 1 年测试，2010 → 2025，全部拼接成一条样本外净值。
- 成本 1× / 2× / 3×。
- Regime 拆分：2015 股灾、2016–2018、2019–2021、2022–2025。
- 参数敏感性：持有期 5/10/20 日、持仓数 30/50/100、缓冲带宽度。
- **最终验收**：只有 2× 成本下仍满足 §1.1 全部门槛，才进入小资金实盘跟踪。
