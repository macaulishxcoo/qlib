# 低名义价格作为显式因子 —— 正交性与增量检验（结果：`reject`）

| 项 | 值 |
|---|---|
| 协议 | `research/protocols/a_share_lowprice_factor_protocol_v1.md`（design_frozen_before_data） |
| 脚本 | `scripts/analyze_a_share_lowprice_incremental_v1.py` |
| 判定 | **`reject`**（显式加入使全期 −2.73pp、holdout −3.78pp） |
| 日期 | 2026-09-13 |

## 1. Q1 正交性：lowprice 确实与五因子基本独立

`corr(lowprice, X)` 的截面 Spearman 相关（255 期均值）：

| X | corr |
|---|---|
| `ep` | −0.0474 |
| `bm` | **+0.3648**（最强，合理：低 P/B 常伴低股价） |
| `div_yield` | +0.1439 |
| `accruals` | +0.0879 |
| `g2` | −0.1171 |
| **`composite5`** | **+0.1743** |

**与 composite5 的 \|corr\| = 0.174 ≪ 0.5 门槛** → **不是价值因子的重复表达**，
是一个相对独立的信号。Q1 通过。

## 2. Q2 增量检验：显式加入反而显著变差

| 阶段 | **A** comp5+价格过滤（当前策略） | **B** comp6+价格过滤 | **C** comp6 无价格过滤 |
|---|---|---|---|
| development | +24.68% | +19.36% | +19.36% |
| confirmation | +10.41% | +12.41% | +12.47% |
| holdout | +20.66% | +16.88% | +16.77% |
| new_coverage | −10.04% | −13.88% | −14.51% |
| **full** | **+16.35%** | +13.63% | +13.56% |
| full IR | **1.378** | 1.117 | 1.111 |

**B − A = −2.73pp（full）/ −3.78pp（holdout）/ −3.84pp（new_coverage）**
→ **`reject`**：显式加入 lowprice 使策略全面变差。

## 3. 这个"失败"给出的两个真信息

### 3.1 价格可行性过滤的**全部价值**就是低价倾斜（已被证实）

```text
B = comp6 + 价格过滤 :  +13.63%
C = comp6 (无过滤)   :  +13.56%
差异                 :  +0.07pp  ← 几乎为零
```

一旦 lowprice 被显式建模，价格过滤**几乎不再提供任何增量**。
这反过来证明：价格过滤此前那 +2.52pp **确实全部来自低价倾斜**
（另加少量仓位利用率），不是别的机制。与上一轮的归因一致。

### 3.2 但低价效应**用"约束"实现 优于 用"因子"实现**

```text
A = comp5 + 价格过滤(隐式低价)  :  +16.35%   ← 最好
B = comp6 + 价格过滤(显式低价)  :  +13.63%
```

两者都含低价暴露，但**隐式（只剔除最贵的约 10%）明显优于显式（在复合分里给低价高权重）**。
合理解释：显式建模会**激进地加载最便宜的那批股票**，
而 `lowprice` 单因子本身的 `new_coverage` 段是 **−24.04%**（极端低价端近期很差）。
**约束型实现只做温和倾斜，反而更稳。**

> **这是一个反直觉但有用的结论**：同一个效应，作为**可行性约束**施加比作为**因子权重**施加更好。

## 4. 处置

| 项 | 处置 |
|---|---|
| 显式加入 composite6 | **不采纳** |
| 保留价格可行性过滤 | **保留**（其价值已确认为真实低价倾斜） |
| 当前最终策略 | **A 臂维持不变**（五因子 top30 + 行业cap3 + 毒尾否决 + 价格可行性过滤） |

**协议起到了它该起的作用**：这一轮本可以让策略看起来"多了一个因子"，
但预先冻结的判定规则挡住了它，避免了 −2.7pp 的退步。

## 5. 结论边界

1. `lowprice` 与五因子基本正交这一事实**仍然成立**，只是它**以约束形式**而非因子形式生效。
2. 未测：把 lowprice 以**温和权重**（而非等权第 6 个 rank）加入是否会改善；
   但那是参数扫描，且已在 A 臂中以约束形式实现，**不再追**。
3. 仍未解决：时间维度样本外（依赖前瞻记录）。
