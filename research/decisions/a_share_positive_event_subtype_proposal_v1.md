## 1. 立项依据与治理说明

### 1.1 动机：负面研究的镜像 + "利好兑现"的全市场检验

负面事件分类型研究已闭环：经营类/资金类"利空出尽"（正超额），制度类（ST 戴帽）与
交易类（跌幅上榜 T5）持续负漂移，T5 已 adopted 为月度剔除层（holdout +0.74pp /
new_coverage +20.33pp）。**但正面事件从未被系统拆分研究**——现有结论只是几个"混合平均"：

| 既有结论 | 性质 | 未回答的问题 |
|---|---|---|
| PEAD 关闭（正负公告均正超额、负向更大） | 财报公告的混合平均 | 业绩**预告**（forecast）的正面类型单独行为如何？（PEAD 用正式财报，预告数据 8/13 才入库，从未消费正面类型） |
| 事件流 labelfix 复核（龙虎榜全部 −2.85%/20d，注意力反转） | 全部上榜的混合 | **涨幅类上榜**（涨停/连板/大涨）单独行为如何？（只拆过跌幅类 T5，正向 reason 半边从未拆） |
| 增持 +0.75%/20d（t=+4.44） | labelfix 复核中的一行 | 增持是否独立成立、分年度是否稳定？（无独立立项、无组合层验证） |

本方向把上述三个"未拆的正半边"按类型拆开（P1 经营类-业绩预告正面类型、P2 资金类-增持、
P3 交易类-涨幅上榜），检验各类型事件后 10/20/40 日市场调整超额的方向、稳定性、动量
正交性与组间差异——**回答"利好兑现（见光死）是否 A 股全市场普遍成立"**，将用户对
智谱（02513.HK）单票的观察（发布 GLM-5.3 利好、股价连跌）升级为可检验假设。

### 1.2 与已测路线的关系（正交性声明）

| 已测路线 | 结论 | 与本方向的关系 |
|---|---|---|
| PEAD（关闭） | 正负公告均正超额（利空出尽）、2026 反转 | 本方向不重测财报公告混合效应；P1 用**业绩预告**（forecast，2026-08-13 新入库），与 PEAD 的财报公告是不同信息时点（预告早于财报 1-2 个月）。若 P1 与 PEAD 结论一致（正超额），则确认"公告效应整体反转市特征"；若不同（负超额=兑现），则预告是独立信号 |
| 事件流 labelfix（龙虎榜全部 −2.85%/20d） | 注意力反转：上榜=关注度峰值→回落，与买卖方向无关（E2 净买净卖均负） | **本方向不重测全部上榜**；P3 只拆 reason 正向半边（T5 的镜像）。labelfix 的"全部负漂移"是本方向 P3 的直接先验 |
| 负面分类型（T5 adopted） | 跌幅上榜 −1.87%/20d 负漂移 | P3 与 T5 同源（top_list reason 分类的正/负半边），互为镜像对照——若 P3 负漂移与 T5 同向，则"上榜=注意力反转"机制（而非"恐慌"或"利好"）得到双侧确认 |
| 指数调整（not_supported） | 纳入=追高→均值回归 | 与 P3 机制同族（被动买压/拥挤），结论互相印证而非重复（不同事件源） |
| 日频反转 S1 / 换手率偏度（关闭） | 裸反转负 IC、组合层不可交易 | P3 若显著负漂移，其价值在于**事件条件**（上榜=情绪极端）而非裸反转——组合层必须过扣成本回测（同 T5 教训） |
| 价值陷阱（adopted） | 财务恶化状态截面 | 状态截面 vs 事件窗口，机制链不同（同负面研究 §1.2 表述） |

**本方向的独立增量**：三个"正半边"（预告正面类型 / 增持 / 涨幅上榜）在此前所有实验中
均未作为独立事件集检验过；且事件层若通过，组合层将首次验证**正面事件的剔除层用法**
（"利好兑现股"剔除）——这是负面 T5 剔除层的机制互补（T5 剔除"正在被抛售"的，P 类
剔除"刚被爆炒/刚兑现"的）。

## 2. 选题

**正面事件分类型研究**：将"正面公告/正面事件"按**事件类型**（经营类-预增/略增/扭亏/续盈、
资金类-股东增持、交易类-涨幅上榜）分组，检验各类型事件后 10-40 个交易日内是否存在
方向一致、非动量代理的市场调整超额；类型间是否存在显著行为差异（镜像负面研究的
ANOVA 主检验）。

**与"为什么跌"主线的衔接**：项目主线已确立"反转市特征贯穿所有事件形态"（龙虎榜反转、
趋势状态反转、指数纳入负效应、跌幅上榜负漂移）。本方向检验这条主线的**正面半边**：
若涨幅上榜也负漂移（利好兑现），则"事件定价"规律统一为"**事件=热度峰值→回落**"；
若增持正漂移（利好延续），则找到主线的一个**例外**——两者都有价值。

**可交易输出（不做空）**：
- 显著负漂移类型 → **剔除层候选**（把"近期利好兑现/被爆炒"的股票从月度多头名单剔除，
  复用 v11/v12 过滤层验收口径）；
- 显著正漂移类型 → **入选信号候选**（事件层记录结论，入选层组合验证另行立项，本轮不做）。

## 3. 五项评审

### 3.1 经济机制（为什么可能有效）

1. **注意力反转 / 拥挤交易（P3 涨幅上榜）**：涨停/连板/大涨上榜 = 关注度与买入拥挤度
   的峰值。T+1 制度下涨停日无法买入，次日开盘买入者天然接在高位；乐观者（异质信念
   中边际最乐观的一批）在榜前已买入，边际买家耗尽 → 均值回归。Miller (1977) 卖空
   约束下超买无法被空头即时修正，只能靠时间回落。**labelfix 已给直接先验：龙虎榜
   全部上榜后 −2.85%/20d，且净买净卖无差异（与方向无关，纯"上榜"效应）**——P3 是
   该机制的正面形态检验。
2. **利好落地 / 预期透支（P1 业绩预告正面类型）**：预增公告公布前，股价可能已随
   预期炒作上涨（题材预热的普遍模式）；公告落地后若无**超预期**成分（预增幅度 vs
   市场已price-in的幅度），即"利好兑现"。但负面研究显示 T1（预亏/预减）反而"利空
   出尽"（+0.47%/20d）——A 股公告效应的方向可能整体与成熟市场相反。**P1 检验的是：
   正面预告是"兑现"（负漂移）还是"延续"（正漂移，分析师上修滞后机制）**。
3. **内部人信号 / 真金白银（P2 增持）**：股东/高管增持 = 内部人信息 + 承诺成本。
   与减持（T3，利空出尽 +0.53%）不同，增持可能携带持续的正面信息（增持通常分阶段
   实施、后续有回购/业绩配合）。labelfix 复核显示增持 +0.75%/20d（t=+4.44）正超额——
   **若 P2 独立成立，将是"反转市主线"的第一个例外，需谨慎复核**（样本、分年度、
   是否被增持潮政策窗口驱动）。

**可证伪性核心**：若三类正面事件行为完全相同（全部兑现负漂移 或 全部无效应），
"类型差异"主张即被证伪；若 P3 负漂移被动量解释，则该类型关闭（上涨动量代理）。

### 3.2 可得时点（PIT 可行性）

| 事件类型 | 数据源 | 事件日 | 可得性状态（2026-08-17 实测） |
|---|---|---|---|
| P3 交易类-涨幅上榜 | `a_share_events_daily_v1/raw/*top_list.csv.gz`，reason 含正向关键词 | `trade_date` | ✅ 全量 1113 天：正向 reason **38,381 条**（负向 17,930，T5 同源） |
| P2 资金类-增持 | 同上 `*stk_holdertrade.csv.gz`（`in_de == 'IN'`） | `ann_date` | ✅ 抽样 1/7 文件 IN=1,492 条 → 全量约 **1.0 万条**；holder_type 分层（P/G/C）可用 |
| P1 经营类-正面预告 | `a_share_forecast_v1/`，`type ∈ {预增, 略增, 扭亏, 续盈}` | `ann_date` | ✅ 预增 6,422 + 扭亏 2,229 + 略增 1,719 + 续盈 245 = **10,615 条** |

样本量：三类均 ≥1 万条，支撑分类型 t 检验与分年度方向检验（镜像负面研究 T1~T5 的
样本规模）。

### 3.3 周期匹配

- 事件频率：预增集中在 1/4/7/10 月预告期；增持全年分布（近年政策鼓励增持潮，样本
  有季节性）；涨幅上榜与行情热度同频。事件触发调仓，非事件月不动 → 换手低；
- 持有期 10-40 日：同负面研究；
- 作为剔除层：只**删除**名单中事件股，不引入额外买入 → 换手零增加（同 v11 定位）。

### 3.4 容量与风险

- 作为剔除层不引入容量约束（同 v11）；
- 需分层报告：规模/行业/事件规模（p_change_min 分档、change_ratio 分档、holder_type）；
- 风险 1：**涨幅上榜天然与"强势/上涨动量"重叠**（镜像 T5 的下跌动量风险）——动量
  正交化（事件前 20 日收益分层）是必须闸门；
- 风险 2：涨停日无法买入——事件日若涨停，入场从 T+1 开盘（协议标签 open(t+H)/open(t)
  口径天然 T+1 开盘入场）；若 T+1 仍一字涨停则买不进，如实标注（与负面研究同口径）；
- 风险 3：2026-07~08 行情复权因子异常（stage2 已记录）——事件窗口止于 2026-07，同
  负面研究；
- 风险 4：P1 预增幅度 vs 一致预期无法完全还原（无一致预期数据）——"是否超预期"
  用预增幅度分档近似，结论表述不夸大。

### 3.5 可证伪性（失败时能说清死的是哪个机制）

| 失败情形 | 结论 | 后续动作 |
|---|---|---|
| 三类行为无显著差异（全部兑现/全部无效） | 正面事件无类型差异，"利好兑现"是普遍规律（若全负）或正面事件无信息（若全零） | 关闭归档；若全负则主线"事件=热度峰值"规律统一，负面 T5 与其互证 |
| P3 负漂移被动量解释 | 涨幅上榜是上涨动量换皮 | P3 关闭，P1/P2 独立判定 |
| P1 无效应（预增不涨不跌） | 预告正面类型无独立信息（与 PEAD 混合平均自洽） | P1 关闭，记录 |
| P2 正漂移但分年度不稳定（仅增持潮年份） | 政策窗口驱动，非稳定 alpha | P2 关闭或降级为观察 |
| 仅个别规模/行业层有效 | 非系统性效应 | 记录，不采纳 |

## 4. 立项自检（方法论三问，不构成门槛）

1. **它服务哪个决策？** 三条线的决策：(a) 日频/事件线——"利好兑现"是否全市场成立，
   与 T5 互证形成"事件定价"完整图景；(b) 月度线——正面事件剔除层（"被爆炒/刚兑现"
   的股票从价值名单剔除）是否改善 holdout/new_coverage；(c) 认知——增持是否主线
   例外。不做会怎样：用户的智谱观察停留在单票直觉，P3/P1/P2 的正半边永远是"未测"。
2. **最小成本版本是什么？** 复用 `analyze_a_share_negative_event_subtype_v1.py`
   （正确 open-to-open 标签 + 动量正交化 + ANOVA 骨架），仅改"事件集定义+分组"
   （T 集 → P 集，reason/in_de/type 过滤条件镜像翻转）。零新增下载。半天到一天可跑通。
3. **验收标准是什么？** 见 §5.3（镜像负面研究：事件层 |t| 从紧 + 分年度 ≥3/4 同向 +
   动量正交化通过；组合层仅对显著负漂移类型做剔除层，双门槛冻结）。

## 5. 最小实验设计（一轮，冻结）

### 5.1 事件类型定义（冻结，不做搜索）

| 类型 | 定义 | 事件日 | 数据 |
|---|---|---|---|
| P1 经营类-正面预告 | `forecast.type ∈ {预增, 略增, 扭亏, 续盈}`；分层：p_change_min 分档 | `ann_date` | `a_share_forecast_v1/` ✅ |
| P2 资金类-增持 | `stk_holdertrade.in_de == 'IN'`；分层：holder_type（P/G/C）、change_ratio 分档 | `ann_date` | `a_share_events_daily_v1/` ✅ |
| P3 交易类-涨幅上榜 | `top_list.reason` 含正向关键词（"涨幅偏离/涨幅达到/连板"等，映射规则实验前冻结） | `trade_date` | `a_share_events_daily_v1/` ✅ |
| C 对照 | 无事件股票（隐含于市场调整超额口径，同负面研究） | — | 母池 |

- P3 的 reason → 正向映射规则**实验前冻结**（镜像 T5 的负向映射，规则文本见协议，
  不事后调整）；与 T5 的 reason 映射互斥（正/负半边不重叠，其他 reason 排除）；
- 多重事件重叠规则（冻结）：同股同日多事件 → P1 > P2 > P3 优先级取主事件；同股
  20 日内多事件 → 仅保留首个（与负面研究一致）；
- 分年度报告（2022-2025 主检验，2026H1 观察）。

### 5.2 检验框架（复用负面研究管线，仅事件集替换）

- 母池：沪深普通 A 股（非金融），口径同 `analyze_a_share_events_daily_v1.py`
  （`build_universe`）；
- 标签：`r_H(t) = open(t+H)/open(t) − 1`，H ∈ {10, 20, 40}（正确 open-to-open 口径）；
- 超额：市场调整 = 个股收益 − 同期 SH000852 收益（T+1 开盘成交）；
- 过滤：ST/退市整理（事件日 asof）+ 停牌 + 涨停信号日（10%/20% 分板块，镜像负面研究
  的跌停过滤）；
- 窗口：2022-01-01 ~ 2026-07-31；
- 检验 1（事件层）：每类 vs 市场平均的 H 日超额均值 + 单样本 t 检验（|t| 从紧 >2.5）
  + 分年度方向一致性（2022-2025 ≥3/4 年同向）+ 分层报告（规模/行业/事件规模）；
- 检验 2（动量正交化闸门）：事件前 20 日收益 5 组，检验超额是否随动量单调变化——
  **防"涨幅上榜=上涨动量"混淆**；
- 检验 3（组间差异）：P1/P2/P3 的 20 日超额两两 Welch t + 单因素 ANOVA——直接回答
  "经营 vs 资金 vs 交易"正面事件是否行为不同。

### 5.3 验收（冻结，不达标就停）

1. **事件层**（逐类型独立）：
   - 显著**负**漂移（t < −2.5）+ 分年度 ≥3/4 同向 + 动量正交化后仍显著 → **"利好
     兑现"成立**，该类型进剔除层候选；
   - 显著**正**漂移（t > +2.5）+ 分年度 ≥3/4 同向 + 动量正交化后仍显著 → **"利好
     延续"成立**，记录为入选信号候选（组合层另行立项）；
   - 任一条件不满足 → 该类型关闭归档，如实记录失败机制。
2. **组合层**（仅对事件层判"利好兑现"的类型，逐类独立）：剔除层 = 调仓日前 20 交易日
   内有该类事件记录 → 从月度名单剔除（基线 = v8 top15 同构复现，与负面研究同口径
   可比）→ holdout（2023-2025）压力费后年化超额**不降**（容忍 ≥ −0.5pp）且
   new_coverage（2025-07~2026-06）**改善 ≥ +5pp**。
3. 事件层 + 组合层同时满足 → `positive_event_subtype_adopted`（进剔除层候选，是否并
   入实盘管线由用户决策）；任一不满足 → 关闭组合用法。

### 5.4 不做的事（本轮最小实验边界）

- 不做公告文本 NLP；不做"是否超预期"的一致预期还原（用预增幅度分档近似）；
- 不做入选层的组合验证（P2 若正漂移，入选层设计另行立项——因为入选会改变 top15
  构造与换手，需独立协议）；
- 不搜索持有期/事件定义/分组阈值（一次冻结：H∈{10,20,40} 主 20、类型定义如上）；
- 不重跑负面研究/T5/PEAD（引用既有结论）；不重跑龙虎榜全部混合（labelfix 已闭环）；
- 不做模型训练、不做空头组合。
