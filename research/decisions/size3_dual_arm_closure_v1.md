# Size 3 因子假设检验关闭记录 v1

## 1. 决策

状态：`size_axis_structural_confirmed`（2026-09-10）

3 个 Size 因子双臂检验完成，**0 个独立候选**——但本族的价值不在候选，
而在**结构性确认**：规模梯度是微盘域收益的主导轴，且方向与全市场一致、
强度递延。

## 2. 完整结果

| 因子 | 定义 | 域内IC | 域内价差 | 全市场IC |
|---|---|---|---|---|
| size（= -log 总市值，**值越大=市值越小**） | 总股本×未复权价 | **+0.053（5/5 年正）** | Q5−Q1 +0.25%（t=0.71） | **+0.085** |
| float_size | -log 流通市值 | -0.010（3/5） | -0.13%（t=-0.31） | +0.068 |
| nl_size | size³~size 残差 | -0.053（与 size 完全反号） | -0.24%（t=-0.69） | -0.080 |

三个关键读数：

### 2.1 规模梯度在末10% 内部延续（域构建没有吃掉全部规模信息）

size 域内 IC **+0.053、5/5 年为正、全市场 +0.085 同向**——符号约定下
正 IC = 市值越小越强。**即使已经筛选到末 10%，"更小"仍然系统性跑赢
"稍大"**。这正是干净微盘域费前年化 +32.9% 的收益引擎的逐月截面版本，
与此前市值十分位梯度（D1 最小档 +120% 领跑全市场）完全一致。

**但注意它没过候选门槛**（价差 t=0.71）——规模梯度的信息同样呈"均匀
涂抹"形态（与 rsi/avg_turnover 同款失效模式）：每组都略优于相邻组、
无两端跳跃。**它是β（结构性暴露），不是可集中交易的α**——这与此前
"top-N 越小越死、全池等权最优"的组合证据互为印证：规模梯度必须靠
"全池持有"来变现，集中下注单只小票会被其个体风险吃掉。

### 2.2 float_size 与 size 的背离（流通口径弱化）

float_size 域内 IC 仅 -0.010 且方向不稳——**流通市值口径的规模梯度
消失**。解读：微盘域内"总市值小但流通占比高"的票（无大股东锁定）
与"总市值小且流通盘极小"的票行为分化；总市值口径的梯度主要由后者
驱动。对 enhance 的含义：若未来做规模加权，用 total_share 口径。

### 2.3 nl_size 与 size 完全反号（-0.053 vs +0.053）

残差与基础因子精确反号（相关 -1.00 量级）——**在末10% 的窄市值带内，
size³~size 的截面关系近乎线性，残差几乎不含独立信息**，只是 size 的
线性重标。协议 §5.1 预告的"域内方差过小"兑现。全市场口径 nl_size
-0.080 有微弱独立信号（市值曲线在全域是非线性的），但方向与 size
相反意味着它不是"增强小盘"而是"反转极端小盘"——证据不足，归档不
立项。

## 3. 规模轴的最终结论（合并全部证据）

| 证据 | 结论 |
|---|---|
| 域构建（D1 十分位 +120%） | 规模 β 是微盘收益的主体 |
| 本轮（域内 size IC +0.053、5/5 年） | 梯度在域内延续，但均匀涂抹、无组间跳跃 |
| 组合层（top-N 越小越死、全池最优） | 规模 β 只能靠全池持有变现，不可集中下注 |
| nl_size 残差 | 域内无独立信息 |

**规模轴闭合**：它不是"因子"，是微盘域的**地基**——已被干净微盘域
+全池等权的结构完整捕获，任何"规模因子"作为选股信号的尝试都被
组合证据否定。
