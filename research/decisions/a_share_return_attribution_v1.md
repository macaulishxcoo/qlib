# 收益归因 —— 超额到底由哪一部分产生

| 项 | 值 |
|---|---|
| 脚本 | `scripts/analyze_strategy_return_attribution_v1.py` |
| 方法 | 分别跑 B(无否决)/E(否决)/F(否决+价格过滤) 三臂，取日度超额序列做分解 |
| 核心发现 | **基础五因子 alpha 近年长期为负；毒尾否决是"承重"成分** |
| 日期 | 2026-09-13 |

## 1. 全期分解（年化，50 万口径，stress）

| 成分 | 年化贡献 |
|---|---|
| **基础五因子 alpha**（B 臂） | **+8.50%** |
| **毒尾否决**（E − B） | **+4.82pp** |
| **价格可行性过滤**（F − E） | **+2.59pp** |
| **合计（F 臂）** | **+16.99%** ✓ 与 headline 一致 |

三项均为正，**没有一项是靠另一项掩盖的**。

## 2. ⚠ 滚动 12 个月分解：否决才是"承重墙"

| 窗口末 | 基础 alpha | 否决 | 价格过滤 | 合计 |
|---|---|---|---|---|
| 2016-12 | +53.77% | +1.43 | +0.93 | +57.51% |
| 2019-05 | +28.50% | +2.58 | +2.17 | +34.93% |
| 2020-02 | −3.82% | −3.31 | −1.01 | **−7.76%** |
| 2021-09 | +7.70% | +2.94 | **+16.61** | +29.75% |
| **2023-04** | **−16.45%** | **+19.73** | +5.37 | +5.74% |
| 2024-01 | +19.82% | +9.42 | +5.64 | +38.55% |
| **2024-11** | +20.62% | **−10.28** | +0.74 | +9.67% |
| 2025-08 | −6.17% | +4.49 | +1.97 | +0.85% |
| **最近（2026-06）** | **−22.02%** | **+18.41** | −3.19 | **−10.42%** |

### 三条结论

**① 基础五因子 alpha 自 2020 年起长期疲弱**
在滚动 12 个月口径下多次为负（2020-02 −3.8%、2023-04 **−16.5%**、
2025-08 −6.2%、最近 **−22.0%**）。
**价值/质量因子本身这些年并不赚钱。**

**② 毒尾否决是策略的"承重成分"**
在最差的几个窗口里，否决贡献了 +18 ~ +20pp：
- 2023-04 窗口：基础 −16.5% → 否决 **+19.7pp** → 合计 +5.7%
- 最近窗口：基础 −22.0% → 否决 **+18.4pp** → 合计 −10.4%

**若没有否决，最近 12 个月会是 −22%，而不是 −10.4%。**

**③ 但否决也不是永远有效**
2024-11 窗口否决贡献 **−10.28pp**（拖累）。所以否决是"多数时候救命"，
**不是"永远救命"**。

## 3. 这对实盘监控意味着什么（最重要的一节）

**策略的收益来源已经发生结构性转移**：

```text
2016-2019 : 靠【基础价值 alpha】(rolling 高达 +50%)
2020 以后 : 基础 alpha 疲弱, 靠【毒尾否决】扛
```

**必须盯的单一指标：否决的滚动贡献。**

| 若观察到 | 含义 | 建议动作 |
|---|---|---|
| 否决滚动贡献持续为正 | 策略仍在其有效形态 | 维持 |
| **否决滚动贡献转负** | **承重墙失效**，策略将退化为"疲弱价值因子" | **触发复核/降低仓位** |
| 基础 alpha 回升 | 回到 2016-2019 形态 | 无需动作 |

**已把这个指标写入监测要求**（`monitor_strategy_decay_v1.py` 的扩展待办）。

## 4. 结论边界

1. 分解是**加法式**（B / E−B / F−E），不是正交因子归因；
   三项之间存在交互（如价格过滤会改变否决的作用面）。
2. 滚动窗口重叠，相邻窗口不独立。
3. 仍未解决：时间维度样本外。

## 5. 对"策略是否有效"的最终判断（更新）

```text
可以主张
  * 全期 +16.99pp, 三项成分均为正 (基础 +8.50 / 否决 +4.82 / 价格 +2.59)
  * 剔除开发段后 +11.11pp, 仍达标
  * 已过五项独立检验; 风险与暴露画像清晰

必须承认
  * 2016-2019 之后, 策略的超额【主要靠毒尾否决】, 而非基础价值因子
  * 基础价值因子近年为负; 否决在个别窗口也会拖累 (2024-11 −10.3pp)
  * 最近 12 个月 −10.42pp, 承接结构 = 基础 −22.0 + 否决 +18.4
  * 无时间维度样本外
```

**因此该策略更准确的定位是**：
> **一个"以深度价值为底仓、靠毒尾否决做风险剔除"的策略；
> 其近年超额来自否决而非选股 alpha。**
> 这也意味着**否决失效 = 策略失效**，监测必须盯住它。
