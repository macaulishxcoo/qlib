## 2. 选题

**价值陷阱识别**：在主线"便宜"子集（composite 中性化前 50%）内，用财务恶化信号（净利/营收/经营现金流同比为负）识别"便宜但正在变坏"的股票，作为主线质量过滤层剔除之。

**与已测路线的关系**（正交性声明）：

| 已测路线 | 结论 | 与本方向的关系 |
|---|---|---|
| 价值四因子（ep/bm/div_yield/accruals） | 唯一存活的选股 alpha | 全部是**水平因子**（便宜程度/分红/应计水平），**无法区分"便宜且稳定"与"便宜且恶化"**——本方向正是补这个盲区 |
| 盈利现金质量、营运资本质量（已关闭） | 同比**改善**作为正向选股失败 | 信息同源（财务）但**方向相反**：那两个关注"变好"做多头选股，本方向关注"变坏"做负向过滤；用途不同（过滤层 vs 选股信号） |
| PEAD（已关闭） | 正负公告**均正超额**（负向更大=利空出尽） | 见 §3.1 边界说明——本方向不依赖事件窗口，机制链不同 |
| 两融拥挤（rzye_zscore） | IC -0.043，过滤层无增量被拒 | 同为"过滤层"形态，但机制不同（交易拥挤 vs 基本面恶化）；验收口径可参照 v5 的先例 |

## 3. 五项评审

### 3.1 经济机制（为什么可能有效）

三链条叠加，均指向"恶化状态持续期跑输"：

1. **盈利动量（负向）**：公司盈利/营收同比转负后，**恶化通常具有持续性**（经营下行不是单季事件）。市场对"开始变差"的反应缓慢（证实偏差：盈利刚转负被当偶然，连续恶化才确认），从恶化确认到完全定价之间有可交易时滞。这是 Bernard-Thomas 盈利动量机制的负向版，与 PEAD（单次公告事件窗口）是不同机制链。
2. **价值陷阱**：便宜不等于安全。EP/BM 高的股票若基本面持续恶化，估值下移可吞掉便宜（"越跌越便宜"）。主线四因子全部是水平因子，**天然选入正在恶化的便宜股**——过滤层针对的正是这个系统性盲区。
3. **卖空约束（Miller 1977，机制背景）**：A 股融券极难，坏消息缺少空头压价，只能靠持仓者卖出缓慢释放 → 恶化股的负向修正周期被拉长。此条是背景解释，**不是本方向的检验对象**（见下一条诚实标注）。

**诚实标注（与 PEAD 的表面冲突，必须写清）**：PEAD 关闭结论是"负面公告后利空出尽、正负公告均正超额"——这**否定了"公告事件窗口内的负面漂移"**。本方向**不检验事件窗口**，检验的是"报告期横截面上，处于恶化状态的股票（净利/营收/现金流同比为负）在未来 20-60 日相对同域股票是否跑输"。两者差异：事件窗口（公告后 5-20 日）vs 状态截面（报告期标识的未来持有期）。若本方向成立，其机制是"恶化状态持续 + 盈利下修风险"，与"公告后漂移"无关；若 PEAD 的利空出尽在状态层面同样成立（恶化股反而反弹），本方向会被快速证伪——**这是本设计刻意保留的可证伪性**。

### 3.2 可得时点（PIT 可行性）

全部输入已存在于现有数据，**零新增下载**：

| 信号 | 数据列（fina_indicator 归一化文件已有） | 对齐 |
|---|---|---|
| 净利同比为负 | `netprofit_yoy`（另有 `dt_netprofit_yoy` 扣非版） | `available_date <= 月末信号日` 取最新可得版本 |
| 营收同比为负 | `or_yoy`（另有 `tr_yoy`） | 同上 |
| 经营现金流同比为负 | `ocf_yoy` | 同上 |

`fina_indicator` 归一化文件：89 报告期（2009-2026）、带 `available_date` PIT 尾；`load_financials_extended_v1.py` 已实现 available_date 过滤与 ann_date 回填（最新记录），**本轮只需在其列清单上追加上述 3-4 列**，不重建任何东西。

### 3.3 周期匹配

- 恶化是慢变量（季报口径），月度信号快照即可覆盖，**与主线月度调仓同频**；
- 过滤层只**剔除**候选名单中的恶化股，不引入任何额外调仓 → 换手零增加，成本可控；
- 与"低换手、月频、个人资金"约束完全匹配（这是冻结文档 §3 最小路径的定位）。

### 3.4 容量与风险

- 过滤层作用于主线既有 top15/top50 名单内部，**不缩小研究母池、不引入容量约束**；
- 需分层报告：恶化信号的有效性不能集中在最小市值层 / ST / 极端行业（参照分层报告章程）；
- 风险 1：YoY 符号是**粗代理**（单季转负 ≠ 持续恶化），若粗代理信噪比低，可能测不出真实效应——报告期层验时同时看单季与"连续 2 期"两种口径（仅这两种，不搜索）；
- 风险 2：财报 YoY 有基数效应与季节性（尤其 Q1），需按报告期分季报告。

### 3.5 可证伪性（失败时能说清死的是哪个机制）

| 失败情形 | 结论 | 后续动作 |
|---|---|---|
| 便宜∩恶化 vs 便宜∩稳定无显著收益差 | 价值陷阱在 A 股主线域内不存在/已定价 | 关闭，归档，不追加搜索 |
| 恶化组反而跑赢（PEAD 利空出尽的状态版） | 负向恶化被过度定价 | 关闭，与 PEAD 结论自洽（A 股无负面漂移） |
| 仅个别行业/市值层有效 | 非系统性效应，过滤层不成立 | 记录，不采纳 |
| 粗代理（单季）无效但连续 2 期有效 | 恶化需要持续性 | 属口径敏感，如实记录，**仍按冻结规则不追加第三口径** |

## 5. 最小实验设计（一轮，冻结）

### 5.1 信号定义（冻结，不做搜索）

- 恶化信号（布尔，4 个预定义）：
  - `deter_ni` = 1 if `netprofit_yoy < 0`
  - `deter_or` = 1 if `or_yoy < 0`
  - `deter_ocf` = 1 if `ocf_yoy < 0`
  - `deter_any2` = 1 if 以上 3 个中 **≥2 个**命中（复合恶化）
- 口径备注：`netprofit_yoy < 0` 同时可加 `dt_netprofit_yoy < 0` 的扣非对照观察（不计入门槛）；
  分季（Q1 季节性与基数效应）报告。

### 5.2 检验框架（复用既有单因子验证协议结构）

- 母池：沪深普通 A 股（非金融），口径同主线；
- 便宜子集（域）：`composite`（≥3 因子）→ 行业 + log_size 中性化残差前 50%（与日频策略协议的主域定义一致）；
- 信号快照：月末 `available_date <= rebalance_date` 最新版本（复用 `load_financials_extended`）；
- 标签：`r_H = open(t+H)/open(t) − 1`，H ∈ {20, 40, 60}；
- 时间切分：development 2016-2019 / confirmation 2020-2022 / holdout 2023-2025 / new_coverage 2025-07~2026-06；
- 中性化：复用 `ols_residual`（行业 + log_size）。

### 5.3 验收（两条同时满足才采纳过滤层）

1. **IC 层**：域内恶化组 vs 稳定组，40 日中性化收益差显著为负（t 参照从紧口径），
   且分年度方向一致（≥3/4 年同向）；
2. **组合层**：v8 top15 基线 + 剔除 `deter_any2` 过滤层 vs v8 基线，
   holdout（2023-2025）压力费后年化超额 **不降**（容忍 ≥ −0.5pp），
   且 new_coverage（2025-07~2026-06）年化超额**改善 ≥ +5pp**。

任一不满足 → `value_trap_filter_not_adopted`，关闭归档，不追加搜索、不调阈值。

### 5.4 不做的事（本轮最小实验边界）

- 不做事件面板、不做公告日对齐、不做 PIT 历史重建（本轮设计不包含，防止实验膨胀）；
- 不下载业绩预告/快报（数据权限未确认，若需要属另一立项）；
- 不搜索恶化窗口（2 期/3 期/不同阈值）、不搜索组合权重；
- 不做模型训练。
