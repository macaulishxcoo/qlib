# A 股新信息源研究方向：选题决策备忘录 v1

## 1. 决策目的

本备忘录不启动任何实验，也不把某一方向视为既定结论。它用于在新一轮研究前
选择**一个有经济机制、可验证时点、可承受执行成本**的信息源方向。

此前的工作只足以停止“纯 OHLCV 短周期公式 + 一日标签 + 高频换仓”的主线，
不足以直接指定下一种因子。未来策略的股票范围也不能由 CSI1000 的相对历史
表现预设，必须遵守沪深普通 A 股研究母池与分层报告章程。

## 2. 已知约束

| 约束 | 对选题的含义 |
|---|---|
| 价量短周期信号的毛收益不足以覆盖换手成本 | 首选持有期为数周至数月、低换手的信息，而不是再做日内/隔夜公式搜索 |
| CSI1000 只是已研究样本 | 新方向须先在沪深普通 A 股研究母池验证，再报告规模、行业、流动性条件 |
| 现有 Qlib 数据主要是 OHLCV | 新方向必须先解决信息可得时点和历史数据血缘，不能把今日财报倒填到过去 |
| 当前无沪深普通 A 股实盘级证券状态表 | 单因子研究可先做研究母池；策略回测前必须补齐 ST、退市、停牌和容量约束 |
| 个人开发者资源有限 | 每轮只验证一个信息家族、少量预先定义候选；不做自动海量因子搜索 |

## 3. 选题评审标准

任何候选方向先按五项判断，不能只按“看起来收益高”选择：

1. **经济机制**：为什么市场可能没有在信息出现时立刻定价？
2. **可得时点**：是否能得到公告日/交易日快照，且可证明在信号日已知？
3. **周期匹配**：预期持有期是否足以覆盖实际交易成本，而非依赖高换手？
4. **容量与风险**：效果是否只来自最低流动性、ST、退市风险或极端行业暴露？
5. **研究可证伪性**：失败时能否清楚说明失败的是哪个机制，而不是继续改公式？

## 4. 候选方向比较

### A. 财务披露后的盈利改善与质量（推荐优先讨论）

**研究问题示例**：公司披露业绩预告、快报或正式财报后，盈利/收入/经营现金流
是否出现了相对自身历史与同行的改善；该改善是否在未来 20 至 60 个交易日内
仍未被完全定价？

| 项目 | 内容 |
|---|---|
| 信息来源 | 业绩预告、业绩快报、正式财报、财务指标；必须有公告日期 |
| 经济机制 | 披露信息复杂、覆盖不均、投资者对质量差异和持续性反应不足 |
| 合理持有期 | 20 至 60 个交易日，必要时延伸至一季 |
| 典型首批假设 | 盈利改善只有在经营现金流同步改善时才可信；应计利润高的“账面增长”不应获得同样溢价 |
| 优点 | 与价量正交；低换手；可解释；适合日频更新而非日频全换仓 |
| 主要风险 | PIT 处理最严格：报告期、公告日、修订、预告/快报/正式报告不能混淆；部分指标在金融行业不可比 |
| 所需最低数据 | 报告期、公告日、公告类型、原始财务值、修订版本、行业、自由流通市值、历史在市状态 |

该方向的关键不是“使用 ROE”，而是严格定义“哪份报表在什么时候公开、相对什么
基线发生怎样的改善”。如果没有公告日，不能开始验证。

### B. 公司行为与公告事件

**研究问题示例**：股份回购、重要股东增减持、业绩预告、再融资、监管风险等
事件在公告后是否产生方向一致且可交易的漂移？

| 项目 | 内容 |
|---|---|
| 信息来源 | 公告全文或结构化公告字段、公告发布时间、事件状态和后续进展 |
| 经济机制 | 事件解读需要时间；市场参与者对可信度、规模和后续兑现的判断不同 |
| 合理持有期 | 5 至 60 个交易日，取决于事件类型 |
| 典型首批假设 | 已实际执行且规模相对自由流通市值显著的回购，比仅披露计划的回购更可能有后续效应 |
| 优点 | 时点清晰、经济解释强、可低频交易；天然适合“事件发生才调仓” |
| 主要风险 | 事件清洗工作重；同日多事件冲突；公告时点可能在盘中/盘后；样本较稀疏 |
| 所需最低数据 | 证券代码、公告日期时间、事件类型、数值规模、状态（计划/实施/完成）、撤销/更正记录 |

它和方向 A 可以共享公告时间线，但研究上必须先分别验证；不能把大量异质事件
拼为一个“公告因子”。

### C. 估值与慢速风格暴露

**研究问题示例**：在控制行业和规模后，低估值股票是否在未来 1 至 3 个月获得
横截面超额收益？

| 项目 | 内容 |
|---|---|
| 信息来源 | 日度或公告后更新的 PE/PB/PS/股息率，以及财务分母的可得日期 |
| 经济机制 | 风险厌恶、偏好变化或对长期现金流预期的系统性低估 |
| 合理持有期 | 20 至 120 个交易日，通常不适合一日标签 |
| 优点 | 解释直观、换手低、可以成为风险模型或组合约束的一部分 |
| 主要风险 | 常常是风格 beta 而非个股 alpha；不同市场状态会反转；“日度估值快照”可能无法证明 PIT 口径 |
| 所需最低数据 | 带发布日期的财务分母或经验证的日度估值快照、行业、自由流通市值、历史在市状态 |

当前的 `daily_basic` 估值试点协议只是一份草案。它尚未被选为方向，也不能在
没有全 A 数据及 PIT 口径审计前执行。

### D. 融资融券与交易资金行为

**研究问题示例**：融资余额变化、借券/融券变化或异常资金流是否代表信息交易，
并在未来 1 至 20 个交易日持续？

| 项目 | 内容 |
|---|---|
| 信息来源 | 融资融券明细、资金流、龙虎榜等交易行为数据 |
| 经济机制 | 部分交易者拥有信息或存在被动资金流，价格调整有滞后 |
| 合理持有期 | 1 至 20 个交易日 |
| 优点 | 可能比财报更及时，适合日频系统 |
| 主要风险 | 仍偏短周期，容易拥挤；数据口径常变化；容量、冲击成本和涨跌停影响很大 |
| 所需最低数据 | 每日明细、标的覆盖范围、历史制度口径、成交额、涨跌停/停牌状态 |

该方向并非不可做，但与已失败的短寿命价量路线距离较近。它应排在低换手基本面/
事件研究之后，而不是作为当前第一个主线。

## 5. 不建议作为首个方向的事项

| 做法 | 不建议原因 |
|---|---|
| Alpha101/Alpha191 扩库 | 仍主要是 OHLCV 重组，不能优先解决信息源同质化 |
| AlphaGen、gplearn、PySR 海量搜索 | 候选数量会远超独立样本，增加数据窥探；适合已有可靠数据与假设后的辅助工具 |
| 更复杂深度学习模型 | 不能补齐未输入的信息，也会让时点、风格和成本问题更难诊断 |
| 先指定 CSI1000/微盘池 | 把历史选择结果误作市场结论，且易将容量与风险暴露当成 alpha |
| 直接做完整多因子模型 | 未先确认任一新信息源存在独立单因子证据 |

## 6. 推荐的决策顺序

建议先选择方向 A 作为**讨论起点**，但不把它自动确认为执行任务。理由是它与
已失败路线的正交性最高、预期持有期最长、个人可执行性最好，也最容易把研究
问题表述为可证伪的假设。

下一次讨论应只回答三件事：

1. 是否以“财务披露后的盈利改善与质量”为第一家族，还是选择 B/C/D；
2. 若选 A，首个问题是“盈利改善的质量”还是“公告事件漂移”；
3. 你能接受的预期持有期、最大换手率和单票容量约束是什么。

确认后，才为**一个**研究问题定义最小数据规范和时间边界；仍不能在同一步
下载数据、开发因子、训练或回测。
