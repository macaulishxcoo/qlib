## 2. 三条主要结论

### 2.1 市场中性**没有达成**——判据无一满足

冻结判据是 `|corr(超额,市场)| < 0.10` **且** `上下行捕获差 < 0.20`。

| 变体 | \|corr\| | 捕获差 | 达标 |
|---|---|---|---|
| V0 | 0.413 | 0.54 | ✗ |
| V4 | 0.310 | 0.32 | ✗ |
| **V5（最中性）** | **0.239** | **0.29** | **✗** |

**即使同时中性化 beta、动量、波动、换手、价值，超额与市场仍是显著负相关（−0.239）。**

### 2.2 代价：全中性让超额**腰斩**

```text
V0 全期 +16.99%  ->  V5 全期 +8.20%      代价 −8.78pp (超额损失 52%)
IR   1.366       ->  0.666               代价 −0.700
```

**拆解代价来源**：

| 中性化对象 | 单独代价 |
|---|---|
| beta | **−1.58pp（负代价，即收益增加）** |
| 动量 | +5.28pp |
| 波动 | +6.24pp |

→ **代价几乎全部来自"动量"和"波动"两个维度**，而不是市场暴露本身。

### 2.3 意外发现：**中性化 beta 是"免费"的，甚至赚钱**

V1 是唯一比基线更好的变体：

```text
全期  +16.99% -> +18.56%   (+1.58pp)
IR     1.366  ->  1.405    (+0.039)
最近1年 −10.72% -> −15.18% (变差 4.5pp)
2020起 +11.11% -> +11.73%  (+0.62pp)
```

**含义**：策略原本带着**不受欢迎的 beta 暴露**（高 beta 在下跌时拖累），
把 beta 中性掉之后，风险调整后收益改善。
**这是一个可以直接采用的低风险改进**——但要注意最近一年会变差 4.5pp，需权衡。

## 3. 一个重要的诊断副产品：近期亏损**就是价值暴露**

| | V0 | **V5（价值已中性化）** |
|---|---|---|
| 最近 1 年 | **−10.72%** | **−0.07%** |
| 全期 | +16.99% | +8.20% |

**价值暴露一旦中性掉，最近一年的亏损几乎消失。**
→ 这是"近期跑输 = 价值因子回撤"的**直接证据**，与收益归因的结论一致
（基础 alpha 最近 −22.0%，靠否决扛回 +18.4pp）。

**但代价是**：全期超额同时从 +16.99% 掉到 +8.20%。
→ **价值暴露既是最新一轮亏损的原因，也是长期超额的全部来源。二者不可分割。**

## 4. 风格中性化**没有削弱防御性**（与预期相反）

| 变体 | 上行捕获 | 下行捕获 |
|---|---|---|
| V0 | 0.94 | 0.40 |
| V5 | 0.95 | **0.66** |

中性化后**下行捕获从 0.40 升到 0.66**（防御性变弱），
**上行捕获几乎不变（0.94→0.95）**。

→ 所以 corr 只从 −0.413 改善到 −0.239：**亏得更多了，但没有赚得更多**。
这说明**"防御性"不来自被中性化掉的那些风格暴露**。

**最可能的来源（未验证）**：**毒尾否决本身**。
它系统地剔除"近期涨幅大、波动高"的标的——而这类标的正是在市场急涨时领涨的。
**即：否决天然是一个"降低上行参与"的装置。**

## 5. 结论边界

1. 本协议**只做减法、未扫参数**，因此不引入新的过拟合风险。
2. `beta_60` 用等权全池做市场代理；换用中证1000 可能略有差异。
3. 仍是同一市场同一时段，不构成时间维度样本外。
4. **未测**：V5 再叠加"关闭毒尾否决"，以验证 §4 的假设。这是本结果自然引出的下一步。
