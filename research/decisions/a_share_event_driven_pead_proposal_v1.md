## 2. 选题

**正式财报公告后漂移（PEAD，Post-Earnings Announcement Drift）**：财报披露后的
复杂信息被市场逐步吸收，公告后 5-20 日价格继续朝公告方向漂移。

与已测路线的关系：PEAD 是**基本面信息驱动**，与已证伪的"价量驱动"（Alpha158、
主升浪、日频估值）正交；与已验证的短周期"强者恒强"（S1 T2）互补——这是短周期
尚未测过的唯一大信息类别，且**天然事件触发调仓**（符合个人资金 + 日频信号 +
事件触发的架构）。

## 3. 五项评审

| 标准 | 评估 |
|---|---|
| **1. 经济机制** | 财报信息复杂、覆盖不均，A 股散户解读能力弱 → 价格对盈余信息反应不足，逐日漂移。文献上 PEAD 是最稳健的异象之一，A 股弱于美股但存在 |
| **2. 可得时点** | 事件日 = `ann_date`（公告日），已核实 2022 后 9.9 万事件、5756 股、每年 2 万+；公告日即信号日，无未来函数（不依赖 available_date，可用性成立） |
| **3. 周期匹配** | 公告后持有 5-20 日，事件触发调仓（非事件日不动）→ 低换手，成本可控，符合个人资金规模 |
| **4. 容量与风险** | 全市场事件（财报季集中，非依赖最低流动性）；ST/退市可过滤；需报告行业暴露与市值分层；财报季集中是执行风险（需记录） |
| **5. 可证伪性** | 失败能区分三种机制：PEAD 在 A 股无效 / 事件定义不当 / 仅个别行业有效——而非继续改公式 |

## 4. 最小实验设计（一轮，冻结）

- **事件**：`fina_indicator` 的 `ann_date`（正式财报公告日），母池（沪深普通 A 股）
- **信号（先最简单，不搜索）**：公告日 T，未来 5/10/20 日市场调整超额（相对 SH000852）
- **事件组 vs 对照组**：公告股票 vs 同窗口非公告股票；按"盈余方向"粗分层（财报净利
  yoy 增速 > 0 / < 0）观察漂移是否方向一致
- **检验窗口**：2022-01-01 ~ 2026-07-31（与既有检验可比）；分年度 + 财报季集中段报告
- **验收**：公告后 5-20 日市场调整超额显著为正且方向一致、非仅个别行业/市值段、
  与短周期强势正交 → `pead_viable`（进 S2 组合回测）；否则关闭并归档
- **不做**：业绩预告/快报（数据缺失）、公告文本情绪、事件同日冲突的复杂清洗、
  多事件叠加——均为后续立项
