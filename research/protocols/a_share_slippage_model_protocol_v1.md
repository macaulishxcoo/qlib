# 滑点 / 冲击成本模型 —— 协议 v1

状态：`design_frozen_before_data`

## 1. 问题

现有回测只计**佣金**（base 0.05/0.15%，stress 0.10/0.30%，最低 5 元）+ 整手。
**未计**买卖价差与市场冲击。而本策略池以中小市值为主体，滑点不可忽略。

目标：给出该策略在 **50 万真实执行**下的**净超额区间**。

## 2. 冻结的滑点模型

对每一笔成交（单边）：

```text
participation = 成交金额 / ADV20            (ADV20 = 过去20日日均成交额)
half_spread   = 0.5 × tick / price          (tick = 0.01 元, A股最小报价单位)
impact        = c × sigma_20 × sqrt(participation)
slippage_单边 = half_spread + impact
```

- `sigma_20`：过去 20 日日收益标准差（个股）
- `c`：冲击系数，**冻结为三档情景**，不调优

## 3. 冻结的情景（3 档 × 现有 2 个佣金档）

| 情景 | c | 含义 |
|---|---|---|
| **乐观** | 0.3 | 只用价差 + 很小的冲击 |
| **中性** | 0.5 | 方根冲击模型的常用量级 |
| **保守** | 1.0 | 冲击系数取上界 |

**另加一个极端情景**：`c=1.0` 且把 `half_spread` 按 **1 个完整 tick**（而非半个）计，
用于模拟流动性枯竭时的情形。

佣金档沿用 `base` 与 `stress`。

## 4. 成交金额的口径（冻结）

- 每次调仓，目标组合等权 30 只，单只目标市值 = 当前 NAV / 30
- 被换出的标的按**上一期权重**计卖出金额
- 首期按**全部建仓**计
- ADV20 与 sigma_20 均用 **调仓日（asof）及之前**的数据 → 严格执行纪律，
  不使用成交日之后的信息

## 5. 必须报告

对每个（佣金档 × 滑点情景）组合，报告：

1. 全期 / 2020起 / holdout / 最近1年 **净超额**
2. **IR**
3. **单边滑点的加权均值（bp）**
4. **相对"仅佣金"基线的额外成本（pp/年）**

并给出**净超额的区间**（最好 → 最差情景）。

## 6. 结论边界

1. 方根冲击模型是**行业通行的近似**，不是微观结构精确解；本协议的价值在于
   **给出量级与区间**，而非精确预测。
2. 参数 `c` 三档是**外部假设**，不来自本数据拟合——因此不构成数据挖掘。
3. 未建模：涨跌停无法成交的连锁效应、停牌、大单拆分。
4. 仍是历史回测，不改变"无时间维度样本外"这一缺口。
