# 毒尾否决 + 宽基等权 日频组合 —— 协议 v1

## 1. 状态与问题

状态：`design_frozen_before_data`

**依据（两条独立线的收敛结论）**：

| 线 | 结果 | 共同点 |
|---|---|---|
| 隔夜/日内分解 | IC 达 t=−21 但多头必亏；十分位 D1~D9 是平坦高原 | IC 由单个极端十分位制造 |
| 涨停事件 | 39 个 h×分档单元全负 | 全部是"极端近期涨幅"事件 |

共同结论：**可交易的多头超额不在"买入强势股"，而在"避开极端强势股"。**
否决价值量级 ≈ +3.2pp/年（剔除 `id_mom_20` D10 后全池毛收益 +9.4% → +12.6%）。

**本线要回答的问题**：

```text
Q. 把「宽基等权」作为底仓、叠加「毒尾否决」，在**严格样本外**能否产生
   相对中证1000 与相对等权全池的双重正超额，且扣成本后存活？
```

**为什么这不是"又一次调参"**：本线的关键风险是"否决规则来自全样本事后诊断"。
因此协议强制：
- 否决规则**由机制直接给出，不做任何阈值拟合**；
- **开发段 2018-2021 / 样本外段 2022-2026-06**，判定**只看样本外**。

## 2. 资金约束（必须建模，不可忽略）

用户初次资金 **50 万人民币**。A 股最小交易单位 100 股，故：

```text
持有 N 只等权 -> 每只 500,000/N 元 -> 需 100 × 价格 <= 500,000/N
N = 150  =>  价格 <= 33.3 元
N = 300  =>  价格 <= 16.7 元
```

因此**持仓只数 N 受真实约束**，本线固定 **N = 150**，并在选样时应用
该价格可行性约束 + 20 日均额流动性排序（只作为可实施性代理，
其自身的收益贡献必须**单独归因报告**，不得混入"否决 alpha"）。

## 3. 冻结定义

```text
池      = SH6xx + SZ 000/001/002/003 (沪深主板)
分量    on_1(t) = open(t)/close(t-1) - 1 ;  id_1(t) = close(t)/open(t) - 1
毒尾分  toxic(t) = mean[ pct_rank(id_mom_20), pct_rank(id_vol_20), pct_rank(on_vol_20) ]
          id_mom_20 = sum(id_1, 20) ; id_vol_20 = std(id_1,20) ; on_vol_20 = std(on_1,20)
否决    veto(t) = toxic(t) > 0.90            # 剔除最高 10%，边界冻结
可实施  price_ok(t) = 100 × close(t) <= 500000/150
```

**为什么用复合而非单因子**：诊断显示三个分量各自都能定义毒尾，
事后挑最强的那个即为挑选偏差，故等权复合、**不选**。

## 4. 组合构造（冻结）

- 底仓：等权持有全部**未否决且可实施**的标的，若超过 N=150 则按 20 日均额降序取前 150。
- 调仓：每 **10 个交易日**（主口径）决策一次；另报 5 日。
- 缓冲带：已持有且**仍在可实施可行集前 300 名（2N）内**的标的保留，不因滑出前 150 即卖出。
  **缓冲带必须有界**：首版实现写作"只要未进入否决区就保留"，导致组合无限累积
  （膨胀至 635~875 只、年化换手仅 1.3），已修正为 2N 上界。
- 执行：t 日收盘出信号 → t+1 开盘成交；涨停开盘不可买、跌停开盘不可卖（强制保留）。
- 成本：base 买 0.05% / 卖 0.15%；stress 买 0.10% / 卖 0.30%。

## 5. 冻结的判定

样本切分：**开发 2018-01-01 ~ 2021-12-31；样本外 2022-01-01 ~ 2026-06-30。**
**判定只看样本外段。**

| 结论 | 条件（样本外，全部满足） |
|---|---|
| `supported` | ① 相对**中证1000**扣成本后净超额 ≥ 10pp/年（用户原始目标）；② 相对**等权全池**净超额 > 0；③ 策略 > 底仓（否决确有贡献）在**开发段与样本外段同号**；④ stress 成本下 ①② 仍成立 |
| `partially_supported` | ②③④ 成立但 ① 未达 10pp |
| `not_supported` | ②或③不成立 |

**强制归因报告**（避免把小市值 beta 冒充 alpha）：

```text
总超额(vs 中证1000) = 小市值溢价(底仓 vs 中证1000) + 否决贡献(策略 vs 底仓) + 选样贡献(150只 vs 全eligible池)
```

## 7. 结论边界

1. 只做**多头**，不涉及融券做空；否决只能"避开"不能"做空"。
2. N=150 的流动性选样会带来规模/流动性倾斜，其贡献必须单列（§5 归因）。
3. 样本外段 2022-2026 含 2024-01 小市值流动性危机，是底仓策略的真实压力测试。
4. 不做事后调整：否决阈值 0.90、N、调仓频率、缓冲带全部冻结。
