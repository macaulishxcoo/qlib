# 风格中性化 —— 协议 v1

状态：`design_frozen_before_data`

## 1. 问题

用户观察：策略"市场逆风时表现好，市场表现好时超额为负"。已实测确认：

```text
corr(策略超额, 市场) = −0.413     上行捕获率 0.94 / 下行捕获率 0.40
```

本协议回答：**把风格暴露中性掉，要牺牲多少超额？**

## 2. 可用的风格数据（先核实过）

`data/external/tushare/a_share_style_pit_v1/` 只含**行业 + 市值**（已在中性化里用掉），
**没有现成的价值/成长/动量/波动风格序列**。

→ 因此**自行构造**风格控制变量（透明、可复现），全部用 PIT 数据：
只使用 `asof_date` 及之前的信息。

## 3. 冻结的风格控制变量

| 代号 | 定义 | 说明 |
|---|---|---|
| `beta_60` | 过去 60 日个股收益对**等权全池**收益的滚动 beta | 市场暴露 |
| `mom_12_1` | `close(t−21)/close(t−252) − 1` | 12 个月动量（剔除最近 1 月） |
| `vol_60` | 过去 60 日日收益标准差 | 波动风格 |
| `turn_20` | 过去 20 日换手率均值（daily_basic） | 流动性/投机风格 |
| `value_ctrl` | `mean(pct_rank(ep), pct_rank(bm))` | **价值暴露本身**（用于拆出"多少 alpha 就是价值"） |

## 4. 冻结的变体（不做参数调优）

| 变体 | 中性化解释变量 |
|---|---|
| **V0** 基线 | `l1_code + log_size` ← **当前策略** |
| **V1** | V0 + `beta_60` |
| **V2** | V0 + `mom_12_1` |
| **V3** | V0 + `vol_60` |
| **V4** 全价格风格中性 | V0 + `beta_60 + mom_12_1 + vol_60 + turn_20` |
| **V5** 全中性（含价值） | V4 + `value_ctrl` |

其余一切不变：五因子 composite5、ST 剔除、毒尾否决、价格可行性过滤、
top30、行业 cap3、10 交易日调仓、50 万口径、stress 成本、中证1000 基准。

## 5. 冻结的判定与必须报告的指标

对每个变体报告：

1. **全期 / 2020起 / holdout / new_coverage 净超额**
2. **IR**
3. **`corr(超额, 市场)`**
4. **上行捕获率 / 下行捕获率**（月度）
5. **实际风格暴露残留**（持仓在各风格控制变量上的截面分位均值）

**"中性化成功"的判据（冻结）**：`|corr(超额, 市场)| < 0.10` 且
上行捕获率与下行捕获率之差 < 0.20。

**"代价"的定义**：`V0 全期超额 − Vk 全期超额`。

## 6. 结论边界

1. 本协议**只做减法**，不新增因子，不扫描参数——因此**不引入新的过拟合风险**。
2. 预期代价：V5 会大幅缩水（因为价值暴露就是 alpha 来源）。
   **这个缩水幅度本身就是结论**，不是失败。
3. 仍是同一市场同一时段，不构成时间维度样本外。
4. `beta_60` 用等权全池做市场代理（与策略池一致），不用中证1000（避免口径混淆）。
