## 2. 研究问题（冻结）

**美股隔夜收益对 A 股次日"开盘跳空 / 全日收益 / 日内收益"的传导系数与稳定性如何？**

时间关系（关键）：美股交易日 T 收盘发生在北京时间 T+1 凌晨 04:00（夏令时）/05:00（冬令时），
在 A 股 T+1 日开盘（09:30）之前 → 研究映射为 **美股 T → A 股 T+1**，不存在"同日"关系。

三个依赖变量口径（教科书的分解，决定研究价值）：
1. `gap`（开盘跳空）= 隔夜信息在**集合竞价阶段**被定价的份额；
2. `intraday`（日内收益）= 开盘之后**是否还有持续传导**（唯一可能有可交易价值的成分）；
3. `c2c`（全日收益）= 总量（= gap 与 intraday 的合成）。

## 3. 机制假设（预注册，可证伪）

| # | 假设 | 机制 | 可证伪预测 |
|---|---|---|---|
| H1 | 一次性定价 | 隔夜风险溢价在集合竞价即时消化 | β_gap 显著、β_intraday ≈ 0 |
| H2 | 日内持续传导 | 投资者对隔夜冲击反应不足，开盘后继续漂移 | β_intraday 显著 ≠ 0 |
| H3 | 不对称传导 | 恐慌显著强于乐观（下跌记忆效应） | 跌日 β 显著大于涨日 |
| H4 | 行业异质 | 科技链（纳指→电子/计算机/传媒）跟随最强 | 申万行业 β 差异显著 |
| H5 | 路径中介 | 美股先定价全球风险资产（A50/港股/汇率），A 股跟的是风险偏好而非美股本身 | 控制 XIN9/HSI 后 β 衰减 |

H1 与 H2 是主问题（决定有无日内 alpha）；H3/H4/H5 是结构层，仅当主问题有信号才深入。

### 4.3 口径说明（冻结）

## 5. 变量定义（冻结）

### 5.1 日历配对（信息窗口口径，主）

对每个 A 股交易日 `d`：
- `u_last` = 收盘时刻最晚的、在 A 股 `d` 日 09:15 集合竞价开始**之前**完成收盘的美股交易日；
- `u_prev` = 在 A 股 `d-1` 日 15:00 收盘**之后**最后一个收盘的美股交易日（即 u_last 的前一
  个美股交易日；**若 A 股 d-1 与 d 之间美股仅一交易日，则 u_prev 与 u_last 相邻**）；
- 主口径：
  `R_us_window[d] = close_US[u_last] / close_US[u_prev] − 1`
  （= A 股 d 日开盘前新增的美股信息累计收益；A 股长假时自动为多日累计）；
- 稳健性口径：`R_us_single[d] = close_US[u_last] / close_US[u_last 的前一美股交易日] − 1`；
- 诊断变量：`n_gap_days[d]` = u_prev 与 u_last 之间相隔的美股交易日数（≠1 的配对日单独
  统计并报告，不并入主回归的样本以外——保留全部样本，主回归含全部配对日）。

### 5.2 A 股收益（依赖变量）

- `gap[d] = open[d] / close[d−1] − 1`（收盘→次日开盘的跳空）；
- `c2c[d] = close[d] / close[d−1] − 1`；
- `intraday[d] = close[d] / open[d] − 1`；
- 行业层：`sw_ret[d] = sw_close[d] / sw_close[d−1] − 1`（申万一级 26 行业）。

### 5.3 样本

- 2010-01-01 ~ 最新；主分析窗口 2016-01-01 起（与项目其他数据对齐），2010-2015 仅作背景；
- 时期切分（**预注册，见结果后不得新增**）：2016-2019 / 2020-2021 / 2022 / 2023-2026（H2O 年底），
  另报告全期与分年。

## 6. 检验设计（分阶段）

### P1 指数级主检验（先做）
主组合：`(R_us_window[SPX] → SH000300)`，三个独立 OLS：
- `M1: gap[d] = α1 + β1·R_us[d] + ε`
- `M2: intraday[d] = α2 + β2·R_us[d] + ε`
- `M3: c2c[d] = α3 + β3·R_us[d] + ε`（汇总口径，非独立信息）
- 标准误用 Newey-West（滞后 5）抗自相关；报告 β、t、R²、样本数；
- 滚动相关：120 日窗口 corr(R_us, gap) 与 corr(R_us, intraday) 时序图。

### P2 稳健性（与 P1 同日跑完，报告但不独占主结论）
- 指数组合：IXIC/DJI/RUT → SH000300；SPX → SH000852（小盘）/ SH000905（中盘）；
- 分系数：全期 β 是否 ≥3/4 时期同号；
- 不对称：`U_down = 1{R_us < −0.5%}`，`gap = α + β1·R + β2·U_down + β3·R·U_down + ε`；
  报告 β3（跌日额外斜率）与 β2（跌日截距移动）；
- 状态分层：按 §4.3 的 vol_regime / us_trend 分组报告 β1/β2；
- 假期错位：n_gap_days > 1 的配对日（≤10%）影响检验（剔除 vs 保留）。

### P3 行业结构（仅当 P1 的 β2 显著才做）
- 26 个申万行业逐一 `sw_ret[d] = α + β·R_us_window[d] + ε`；
- 预注册的行业映射（**不按结果挑选**）：科技链组 = 纳指 SPX/IXIC → 电子/计算机/传媒/通信；
  传统组 = DJI → 银行/非银/采掘/化工/钢铁；防御组 = RUT → 医药/食品饮料/公用事业；
- 报告组内 β 均值与排序，检验 H4 的"科技链最强"是否成立（组间差异检验）。

### P4 路径中介（探索层，仅当 P1 显著时做）
- 加入 XIN9（A50）、HSI/HKTECH 作中介变量（两阶段）；检验 H5：
  控制隔夜 A50/恒指收益后，SPX 的 β 是否衰减。

### P5 可交易性（**不自动启动**）
- 仅当 P1 的 β2 显著且满足 §7 全部门槛时，**另立协议**做"美股隔夜信号 → A 股开盘后
  15/30 分钟确认 → 日内交易"的扣费回测（红线：IC 正 ≠ 可交易；跳空本身不可交易）；
- 若 β2 ≈ 0（H1 成立）→ 本方向作为"宏观/风险联动知识"归档，不立策略。

## 7. 预设判定（冻结）

| 口径 | 条件 | 判定 |
|---|---|---|
| M1 β1 | 全期 t ≥ 2 且 ≥3/4 时期同号 | `overnight_priced_at_open`（开盘定价存在） |
| M2 β2 | \|t\| < 2（全期与 ≥3/4 时期均不显著） | `no_intraday_continuation` → **本方向关闭**（H1 确认） |
| M2 β2 | t ≥ 2 且 ≥3/4 时期同为正 | `intraday_continuation_candidate` → 触发 P5 评估 |
| M2 β2 | t ≤ −2 且 ≥3/4 时期同为负 | `intraday_overtrading_reversal` → 触发 P5（反转形态） |
| M3 β3 | 报告 | `conduction_magnitude`：美股 1% → A 股 β3×100 bp（影响程度的量化答案） |
| H4/H5 | — | 仅作结构知识，不单独触发立项 |

**反 snooping 声明**：主结论只基于预注册的主组合 `(SPX→SH000300)` 与上述判定；
P2 的任何子组合不得用于"找出最强组合"；若 P1 主组合不满足而某子组合满足，记为
`conditional_observation` 而非结论，需独立确认期（章程 §7）。

## 8. 不做的事（冻结）

- 不做美股个股/行业指数（无权限；H4 用指数间映射近似）；
- 不做分钟/tick、不做高频、不做自动因子搜索；
- 不引入真实 A50 期货价格（仅用 XIN9 指数做中介探索）；
- 不预选、不事后新增时期切分或状态变量；
- 不在 P1 未通过时启动 P3/P4/P5；
- 不把任何结果直接作为模拟盘/实盘改动依据（归档为知识层）。
