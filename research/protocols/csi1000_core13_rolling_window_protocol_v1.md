# CSI1000 Core13 滚动窗口重训与风格暴露诊断协议 v1

## 1. 目的与背景

此前确认（见 `csi1000_alpha158_execution_attribution_v1`）：

- 固定 B_core13 模型在 2025-2026 测试窗的 IC 仅 0.02，信号本身已接近
  失效；
- 该窗的费后超额主要来自"组合形成缺口"（持仓延续与权重），静态 Top50
  信号在 2026 年已出现反号；
- 模型训练时只输入 13 个原始量价因子，行业与市值仅出现在筛选阶段的
  中性化验证中，**模型本身学到的很可能是小市值/低波动风格暴露，而不是
  剔除风格后的纯 alpha**；
- 原结论建立在 2025-01 至 2026-07 这 376 天单一行情 regime 上。

本协议只回答一个问题：

```text
把评估窗拉长到 2021-2026（覆盖多轮牛熊），在滚动重训并把市值/行业作为
模型特征的前提下，Alpha158 残余 13 因子的真实预测力还剩多少？
```

本实验是**诊断**，不是投产。它不用于选版、不调参，只量化
"滚动重训 + 风格特征"对残余量价因子的影响。

## 2. 信息边界

| 时间区间 | 本实验中的角色 |
|---|---|
| 2017-11-01 至 2018-12-31 | 数据预热与首个训练窗数据 |
| 2019-01-01 至 2026-07-23 | 滚动训练窗与评估窗（后详） |
| 2026-07-24 以后 | 不读取、不预测 |

训练与评估均在本区间内以"滚动前视不泄露"方式划分：任何交易日的预测
只使用该日之前已披露的因子、市值与行业数据，且模型只由该日前 3 年的
样本训练。**不存在未来函数与样本内选择偏差**：两个版本的特征集合与
滚动规则在运行前冻结，运行后不得修改。

## 3. 股票池、标签与数据源

| 项目 | 固定值 |
|---|---|
| 股票池 | Qlib `csi1000` 每日历史成分（PIT，含已退市股） |
| 标签 | `Ref($close,-2)/Ref($close,-1)-1`（与前序实验一致） |
| 行情源 | `~/.qlib/qlib_data/cn_data_2026` |
| 因子 | B_core13 的 13 个固定表达式（STD5/KLEN/STD10/STD60/STD20/MIN60/HIGH0/CORD20/CORR10/MAX5/KUP/CORR20/CORD10） |
| 市值特征 | `log(自由流通市值)`，Tushare 口径 |
| 行业特征 | 申万一级行业哑变量（约 31 类） |
| 市值数据 | `a_share_style_pit_v1`（月度 PIT，2013-12~2025-05）+ `csi1000_neutralization_2025-01-01_2026-07-23`（日频，2025-06 起补全） |
| 行业数据 | `a_share_style_pit_v1/industry_l1_effective_intervals`（PIT 有效区间）+ `csi1000_neutralization_*` 补全 |

市值口径统一为 Tushare 自由流通市值（不复权口径），与既有中性化脚本
`analyze_csi1000_alpha158_neutralization.py` 的 `free_float_market_value`
口径一致。行业归属按 `[in_date, out_date)` 有效区间映射到每个交易日。

## 4. 唯一可比较的两个版本

| 版本 | 特征集 | 含义 |
|---|---|---|
| V1 `core13_plain` | 仅 13 个量价因子 | 纯量价残余因子基线 |
| V2 `core13_size_ind` | 13 因子 + log(自由流通市值) + 申万一级行业哑变量 | 把风格暴露显式放进模型，检验因子独立信息 |

两个版本滚动规则、标签、股票池、模型超参、成本、回测配置完全一致。
**运行后不得增减特征、修改滚动规则或模型参数。**

## 5. 滚动训练规则（预先冻结）

- 训练节点：每 63 个交易日（约一个季度）一个节点，首个节点从
  2021-01-01 前的第 1 个交易日开始，最后一个节点覆盖到 2026-07-23。
- 每个节点：
  - 训练集：节点前 504 个交易日（约 2 年）；
  - 验证集：训练集之后、节点之前的 252 个交易日（约 1 年），用于
    LightGBM early stopping；
  - 预测集：节点起 63 个交易日（约 1 个季度）；只保留该段的预测。
- 模型：`LGBModel`（`qlib.contrib.model.gbdt`），参数与 B_core13 完全
  相同：`loss=mse, colsample_bytree=0.9, learning_rate=0.1,
  subsample=0.9, lambda_l1=205.6999, lambda_l2=580.9768, max_depth=8,
  num_leaves=250, num_threads=20`。
- 特征预处理：按 qlib 惯例仅做 `DropnaLabel` + 标签 `CSZScoreNorm`；
  特征不做跨日标准化（保留原始量纲，与 B_core13 的
  `infer_processors=[]` 一致）。
- 拼接所有节点的预测 → 2021-01-01 至 2026-07-23 的连续日频分数序列。

## 6. 强制报告指标

对每个版本，在 2021-01-01 至 2026-07-23 全区间及分自然年：

1. 日频截面 IC 均值 / ICIR / RankIC / RankICIR / IC>0 占比；
2. 日频 IC 的分年汇总（2021、2022、2023、2024、2025、2026 至今）；
3. `TopkDropout(topk=50, n_drop=5)` 费前、费后（基准成本与压力成本）
   年化超额收益、IR、最大超额回撤、日均换手率；
4. V1 与 V2 的逐项对比（IC 差、分年超额差、回撤差）。

## 7. 固定回测设置

| 项目 | 固定值 |
|---|---|
| 策略 | `TopkDropoutStrategy(topk=50, n_drop=5)` |
| 回测区间 | 2021-01-01 至 2026-07-23 |
| 初始资金 | 100,000,000 |
| 成交价格 | 收盘价 |

## 9. 结论边界

本实验只量化"滚动重训 + 风格特征"对残余量价因子的影响，作为判断
Alpha158 残余价值与后续基本面增强方向的依据。它不授权部署任何版本，
不构成实盘依据。运行完成后停止，等待用户审查。
