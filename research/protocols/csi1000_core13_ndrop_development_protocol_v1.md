# CSI1000 Core13 换仓速度开发实验协议 v1

## 1. 目的与当前状态

本协议只回答一个问题：

```text
固定 Core13 模型的一日预测信号，应该以多快的速度转化为 Top50 持仓？
```

此前已经确认：

- 固定 B 模型的 1 日 Rank IC 为 2.00%，第 3、5、10 日边际 Rank IC
  降至约 0.8%-0.9%；
- 相邻交易日最新 Top50 平均只重合 21.81%，精确更新平均需要替换
  39.09 只股票；
- 现有 `n_drop=5` 的回测主要形成了“少量极高分股票入场 + 大量旧持仓
  延续”的路径，而不是持续跟踪最新 Top50；
- 2025 年旧持仓路径贡献较强，2026 年持有 21 日以上股票已产生明显拖累。

因此需要在开发期比较固定的换仓速度。但本文件只冻结实验设计，**不授权
运行回测**。必须先由用户审查协议，明确同意后才能运行一次完整实验。

## 2. 信息边界

| 时间区间 | 本实验中的角色 | 允许用途 |
|---|---|---|
| 2020-01-01 至 2022-12-31 | 已完成的模型训练期 | 不重新训练，只读取正式 B 模型 |
| 2023-01-01 至 2024-12-31 | 策略开发期 | 比较预先冻结的 `n_drop`，不能称样本外 |
| 2025-01-01 至 2026-07-23 | 已污染的回溯确认期 | 本实验完全不读取、不回测、不参与选择 |
| 2026-07-24 以后 | 严格前瞻期 | 只用于最终冻结版本的观察或模拟交易 |

2023-2024 已参与因子开发和 LightGBM early stopping。因此这里的结果只能
选择一个待前瞻观察的策略版本，不能证明它具有可实盘的样本外收益。

## 3. 固定模型与预测

| 项目 | 固定值 |
|---|---|
| Experiment ID | `279845493254805780` |
| Run ID | `87746817d1924ad887b429044c8ec4c2` |
| 模型版本 | `B_core13`，13 个固定因子 |
| 模型训练期 | 2020-01-01 至 2022-12-31 |
| 模型验证 / early stopping | 2023-01-01 至 2024-12-31 |
| 标签 | `Ref($close,-2)/Ref($close,-1)-1` |
| 股票池 / 基准 | CSI1000 / `SH000852` |
| 数据源 | `~/.qlib/qlib_data/cn_data_2026` |

实验只从正式运行的 `params.pkl` 和 `task` 重建 valid 数据并生成一次
2023-2024 分数。所有策略共享完全相同的预测序列；不得重新训练、改变因子、
模型参数、标签或数据预处理。

预测生成后记录行数、日期、每日股票数和文件 SHA256。所有候选必须读取同一
份冻结预测，避免策略之间出现隐含模型差异。

## 4. 唯一可比较的换仓候选

`topk` 固定为 50，只改变 `n_drop`：

| 候选 | 角色 | 机制含义 |
|---:|---|---|
| 5 | 基线 | 当前策略，每天主动替换约 10% 持仓 |
| 10 | 温和加速 | 理论上约 5 个交易日更新一轮持仓 |
| 20 | 快速更新 | 理论上约 2.5 个交易日更新一轮持仓 |
| 40 | 诊断上界 | 接近每日追踪最新 Top50，预计换手和成本很高 |

不得在查看结果后增加 `1、2、3、15、25、30、50` 等新候选。`n_drop=40`
主要用于检验“最新排名是否值得接近全量追踪”，即使收益较高，也必须通过
后面的成本、换手和稳定性门槛才能成为候选版本。

## 5. 固定回测设置

所有候选使用同一账户和交易限制：

| 项目 | 固定值 |
|---|---|
| 策略 | `TopkDropoutStrategy(topk=50, n_drop=<候选>)` |
| 开发区间 | 2023-01-01 至 2024-12-31；报告实际共同可交易日期 |
| 初始资金 | 100,000,000 |
| 成交价格 | 收盘价 |
| 涨跌停阈值 | 9.5% |
| 最低佣金 | 5 |
| 基准成本 | 买入 0.05%，卖出 0.15% |
| 压力成本 | 买入 0.10%，卖出 0.30% |

压力成本用于约束 CSI1000 小盘股的冲击成本低估。两套成本分别运行，但模型
预测、持仓规则和其他配置必须完全相同。不得根据基准成本结果修改压力成本。

## 6. 强制报告指标

每个候选必须同时报告全期、2023 年和 2024 年：

1. 费用前和两套成本后的年化超额收益；
2. 两套成本后的信息比率和最大超额回撤；
3. 日均换手率、年化成本损耗和订单成交率；
4. 实际持仓与当日最新 Top50 的平均重合率；
5. 实际持仓的平均当前分数排名百分位；
6. 平均持仓年龄，以及 1 日、2-5 日、6-10 日、11-20 日、21 日以上仓位占比；
7. 2023 与 2024 的结果方向是否一致。

模型 Rank IC 对所有 `n_drop` 都相同，不得把同一预测的 Rank IC 重复包装成
某个策略候选的优势。`h>1` 信号衰减指标也不在本实验中重新估计。

## 7. 预先冻结的判定规则

`n_drop=5` 是默认保留版本。其他候选只有同时满足以下条件，才能替换它：

1. 压力成本后，2023 和 2024 两个自然年的年化超额收益都大于 0；
2. 压力成本后的全期信息比率至少比 `n_drop=5` 高 0.10；
3. 压力成本后的“较差年份年化超额”至少比 `n_drop=5` 的较差年份高
   2 个百分点；
4. 压力成本后的最大超额回撤不得比 `n_drop=5` 扩大超过 5 个百分点；
5. 日均换手率不得高于 50%。

如果多个候选同时通过，按以下唯一顺序选择：

1. 压力成本后较差年份年化超额更高者；
2. 差值小于 1 个百分点时，选择日均换手率更低者；
3. 换手率差值小于 1 个百分点时，选择 `n_drop` 更小者。

如果没有候选通过全部门槛，则保留 `n_drop=5` 作为前瞻观察基线，但必须标记
为“机制存在错配、尚无更稳健替代”，不能解释成 `n_drop=5` 已被验证有效。

无论哪个版本胜出，都不得再回到 2025-2026 做二次确认或继续调参。胜出版本
只能从 2026-07-24 以后进入严格前瞻观察或模拟交易。

## 8. 输出与执行约束

获批后应由一个脚本一次性完成全部候选和成本场景，在所有运行结束前不输出
中间胜负结论。输出统一写入：

```text
output/analysis_static/csi1000_core13_ndrop_development_v1/
```

至少包含：

```text
ndrop_development_report.txt
strategy_summary.csv
yearly_summary.csv
holding_alignment_summary.csv
metadata.json
```

运行脚本应保存在 `scripts/`，不得新建 YAML、不得写入默认 `mlruns/`，也不得
修改正式 B 的 MLflow 产物。
