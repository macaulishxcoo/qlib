# 价值/质量多因子月度策略 top-15 基线回测协议 v8

## 1. 状态、问题与授权边界

状态：`design_frozen_before_backtest`

v6 验证的是 top-50（封存期 +11.69%/yr，IR 1.33）。实盘资金 500K 下 top-50
每只约 1 万，操作量大；选择 top-15（每只约 3.3 万）更可操作，但集中度更高、
波动和回撤更大。本协议回答：

```text
把选股数量从 top-50 改为 top-15，其余规则与 v6 完全一致，
封存期（2023-2025-06）压力费后超额是否仍为正且 IR>0，
且最大超额回撤在可接受范围内？
```

通过后，top-15 可作为实盘基线；不通过则如实记录，重新考虑 top-50 或折中。
本协议只授权一次回测，不授权调优 top-k 数量。

## 2. 唯一变动（冻结）

| 项 | v6 | v8 |
|---|---|---|
| TOP_K | 50 | **15** |
| NOTIONAL (ACCOUNT/TOP_K) | 2,000,000 | **6,666,667** |

其余与 v6 完全一致：四因子（ep/bm/div_yield/accruals）≥3 因子门槛 -> 中性化
（行业 OLS + log size）-> ST/退市过滤 -> 容量过滤（参与率 5%）-> 月度换手 ->
T+1 开盘执行 -> 涨跌停 9.5% -> 基准/压力两套成本 -> SH000852 基准。

**容量说明**：回测用 ACCOUNT=100M 以与 v6 可比。实盘 500K 下 NOTIONAL=33,333，
参与率约束几乎无约束力（主板股票 20 日均额普遍 >4000 万）。实盘真正约束是
最小买入单位（100 股/手），此在部署协议中处理，不在回测中模拟。

## 4. 预设判定（冻结）

- 封存期（2023-2025-06）压力费后年化超额 > 0 且 IR > 0 -> `top15_viable`
- 且封存期最大超额回撤 > -35%（比 top-50 的 -11.2% 更宽松，因集中度更高）
  -> `top15_acceptable_drawdown`
- 两个都满足 -> top-15 可用于实盘
- 否则 -> 记录诚实结果，重新考虑 top-50 或折中 top-25

**不授权调优**：不在此协议中尝试 top-20/top-25/top-30 等中间值。

## 6. 结论边界

top-15 更集中，预期年化超额可能高于 top-50（集中度溢价），但最大回撤也会更大。
结果用于判断 top-15 是否可接受为实盘基线，不构成最终实盘参数（仓位比例、
止损规则在部署协议中定义）。
