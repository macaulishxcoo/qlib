# 可实施性成本侧研究 —— 协议 v3

状态：`design_frozen_before_data`

## 1. 为什么转向成本侧

v2 决策记录 §8 已写死下一步方向。三条日频线（隔夜/日内、涨停事件、毒尾否决）证明：

- 截面梯度极薄，唯一稳健效应是"毒尾否决" **≈ +1.3pp/年**；
- 而可实施性成本 **5~8pp/年**（最低佣金 + 整手现金拖累 + 换手）。

**成本侧的空间比信号侧大 4~6 倍**，且不依赖任何新的预测能力。
本协议只调**实现参数**（持仓只数 N、调仓间隔 STEP、佣金口径），
**不动任何信号参数**（否决定义与阈值沿用 v1/v2）。

## 2. 冻结的扫描网格

```text
N     ∈ {30, 40, 60, 100, 150}          # 持仓只数 -> 决定单笔规模
STEP  ∈ {10, 20}                        # 调仓间隔(交易日) -> 决定换手
```

价格可行性随 N 联动：`100 × 价格 <= 500000 / N`（N 越小，可选面越宽）。

## 3. 冻结的成本阶梯（关键：最低佣金是可谈判的）

| 场景 | 买入 | 卖出 | 5 元最低佣金 | 说明 |
|---|---|---|---|---|
| `stress` | 0.10% | 0.30% | **是** | 既有压力档 |
| `base` | 0.05% | 0.15% | **是** | 既有基准档 |
| `base_nofloor` | 0.05% | 0.15% | **否** | 券商免除最低佣金 |
| `retail_best` | 0.015% | 0.065% | **否** | 万1.5 佣金 + 0.05% 印花税，无下限 |

**为什么必须单列"免 5"**：50 万 / N=150 时单笔 3,333 元，5 元 = 单边 0.15%，
是费率本身的 3 倍。**该下限是否可免，直接决定策略可行性**，属于可行动的现实变量，
不是回测假设的微调。

## 4. 冻结的判定

样本切分不变：**开发 2018-01-01 ~ 2021-12-31；样本外 2022-01-01 ~ 2026-06-30。**

对照基准：
- `B1` = 中证1000
- `B0(N,STEP)` = **同参数、同约束、同选样但不施加否决**的组合（即机会成本）

| 结论 | 条件（样本外） |
|---|---|
| `cost_frontier_found` | 存在 (N, STEP, 成本场景) 使相对 B1 净超额 **≥ 10pp/年** |
| `cost_improved_only` | 最优配置相对 B1 净超额 > 0 但 < 10pp |
| `no_feasible_config` | 全部配置相对 B1 净超额 ≤ 0 |

**同时必须报告**：每个配置的仓位利用率、换手、以及"免 5 + 万1.5"下的结果，
以便把"策略不行"与"成本太高"两件事分开陈述。

## 5. 结论边界

- 本协议**不产生新的 alpha**，只回答"给定 1.3pp 的 alpha，成本能压到多少"。
- `retail_best` 场景是**假设**，需用户向券商确认；报告将以 `base` 为主判据，
  `retail_best` 仅作上界参考。
- 不做事后挑选：全部网格结果一并列出，不因某个格子好看而单独汇报。
