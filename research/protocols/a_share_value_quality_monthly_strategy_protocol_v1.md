# 沪深非金融 A 股价值/质量多因子月度策略回测协议 v1

## 1. 状态、问题与授权边界

状态：`design_frozen_before_backtest`

承接同族扩展验证：`ep`、`bm`、`div_yield`、`accruals` 四个水平因子已在
开发/确认/封存三阶段全部通过预设门槛（`replicated_for_strategy_design`）。
本协议首次授权构建**多因子组合信号**并做**月度换手策略回测**，回答：

```text
把四个已验证的水平因子按等权组合成月度选股信号，在保守交易成本、停牌/涨跌停
约束与流动性过滤下，是否能产生扣费后为正的超额收益？
```

本协议授权单策略回测，不授权：调优 topk、加权方式、过滤阈值以美化结果；
根据回测结果修改因子定义；选择"回测最好的"因子子集。

## 2. 组合信号（冻结）

| 项 | 冻结值 |
|---|---|
| 因子 | `ep`、`bm`、`div_yield`、`accruals`（均"越高越好"，已验证） |
| 组合方式 | 每月在当月完整样本内，对每个因子取横截面百分位秩 `rank(pct=True)`，四个因子等权平均 |
| 信号时点 | 月末 `rebalance_date` 用 `available_date <= rebalance_date` 的 PIT 快照计算（与验证完全一致） |
| 数据缺失 | 任一因子缺失的股票当月组合分数为 NaN，不填充 |

不采用 z-score（对异常值敏感）、不按因子单独调权、不加交互项。

## 3. 股票池与可交易过滤（冻结）

| 项 | 冻结值 |
|---|---|
| 母池 | 沪深普通 A 股、非金融（剔除银行/非银），与验证一致 |
| 流动性过滤 | 信号日 `asof_date` 前 20 个交易日平均成交额，剔除当月池内最低 20% |
| ST/*ST | 当前无历史 ST 状态表（数据缺口），**不做 ST 过滤**，报告中明确标注该偏差 |
| 停牌/涨跌停 | 由 Qlib 交易所撮合处理（停牌不可成交、涨跌停 `limit_threshold=0.095`） |
| 选股 | 每月组合分数最高的 50 只（`topk=50`），等权 |
| 持有期 | 月度换手：分数仅在月末更新，两次月末之间持仓不变 |

## 4. 执行时点与标签（冻结）

- 信号在 `rebalance_date` 当日按 `available_date <= rebalance_date` 已知；
- 用 Qlib `TopkDropoutStrategy` 撮合：`t` 日读取信号 → `t+1` 日开盘价成交；
- 成交价 `open`，涨跌停阈值 9.5%，最低佣金 5 元；
- 基准 `SH000852`（CSI1000），与既有回测一致；
- 成本两套：基准成本（买 0.05% + 卖 0.15%）、压力成本（买 0.10% + 卖 0.30%）。

## 5. 回测区间与报告

- 回测区间：2014-01-01 至 2025-06-30（月度市值 PIT 与财报可得区间）；
- 报告口径：全期 + 分验证阶段（开发 2014-19 / 确认 2020-22 / 封存 2023-25）+ 分自然年；
- 指标：费前/费后（两套成本）年化超额、IR、最大超额回撤、日均换手率、年化成本损耗、
  基准年化收益；
- 同时报告组合信号在回测区间的日频 RankIC 作为信号质量对照（应与单因子验证量级一致）。

## 6. 预设判定

- 若压力成本后全期年化超额 > 0 且 IR > 0：记为 `net_positive_stress`，
  进入下一步实盘可交易池细化；
- 若基准成本后 > 0 但压力成本后 <= 0：`net_positive_base_only`，需再评估
  换手与执行；
- 若基准成本后 <= 0：`not_net_positive`，停止该组合方式，不调优。
