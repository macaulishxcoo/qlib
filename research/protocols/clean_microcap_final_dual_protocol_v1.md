## 2. 实验一：N 源 enhance 融合回测（月度）

### 2.1 第零步：融合前相关归并

7 源（Z1 / delta_gpm / pa / bias_std_turn_21d_252d /
bias_std_turn_42d_504d / MACD / return_std_21d）在域内每调仓日计算
截面 rank，取月度序列 Spearman 相关矩阵。归并规则：

- |corr| > 0.60 的簇只保留 |IC 中位|×|t| 最高的一个源；
- 已知待测对：pa~delta_gpm（预期 0.4-0.6）、bias_21d~bias_42d（预期
  0.7+）、MACD~return_std_21d（未知）。

### 2.2 融合信号（冻结）

- 簇内等权 rank 均值 → 跨簇等权 → Z_final；
- 方向统一为"分数高=预期强"；
- 不做权重优化、不做 IC 加权、不做波动率调整（反 snooping）。

### 2.3 回测臂（冻结，单变量=信号）

| 臂 | 信号 |
|---|---|
| fusion_enhance | Z_final enhance（等权×(1+0.5×(rank−0.5))） |
| z1_enhance | 仅 Z1 enhance（已验证基线 +2pp） |
| 各单源 enhance | pa / delta_gpm / 归并后 BIAS / MACD / std_21d（归属分析） |
| pool_ew | 全池等权（基线） |

共同口径：干净微盘域月度重建、月度调仓、T+1 开盘、三档成本
（base 0.15%/stress 0.40%/microcap 0.80%）、2022-01~2026-08、跌停停牌
顺延、崩盘段单列。

### 2.4 判定（冻结）

主判定（microcap 口径 vs pool_ew）：
1. **fusion 净超额 ≥ +3pp 且 IR ≥ 0.5** → `fusion_adopted`（最终形态=
   融合 enhance，进模拟盘评估）；
2. 净超额 (2pp, 3pp)：看 **fusion − z1_enhance 差**——
   ≥ +1pp → `fusion_adopted`；≤ +0.5pp → `keep_z1_only`；
   之间 → `fusion_marginal`（记录，倾向简单性）；
3. fusion ≤ z1 单源 → `fusion_no_increment`（机制重叠吞噬正交性，
   维持 Z1 单源收口）。

### 2.5 风险预告

1. 正面组（pa/delta_gpm）与负面组（BIAS/MACD/std）可能权重互相抵消
   （同一票一边加分一边减分）——融合失败的最大可能原因，预注册接受；
2. 归并后簇数若 ≤3，分散化收益有限，预期值压至 +2.5~3pp；
3. 基本面源的 PIT 月内不更新（季频原料），月度口径下与量价源时效
   混搭（q4 轮已验证可接受）。

## 3. 实验二：Z1 短周期专项（10/15 日 enhance，冻结）

### 3.1 动机

被证伪的是"量价因子+top-N 集中构造+短周期"，**enhance 构造+短周期
从未被测**。Z1 半衰期（周级）与 10/15 日持有期匹配；它是七源中唯一
原生短周期信号。本实验是"灵活调仓诉求"的最后一次定量检验。

### 3.2 设计（冻结）

- 信号：Z1（与月度轮完全同构）；
- 持有期：10 日、15 日（5 日在 top-N 轮已证明换手不可承受，不再测）；
- 构造：enhance 全池加权（无集中度）；
- 成本：三档同上，另加**换手-成本敏感曲线**（10 日 vs 月度的成本差）；
- 对照：pool_ew（月度）、z1_enhance（月度）、月度全池等权；
- 判定（microcap 口径）：
  - 任一周期净超额 ≥ +1pp 且 IR ≥ 0.4 → `short_cycle_viable`（灵活
    调仓诉求重新打开，样本外观察）；
  - 全部 ≤ 0 → `short_cycle_closed`：短周期在微盘域的可行域被组合
    证据（top-N 两轮 + 本轮）完整排除，诉求正式关闭，月度为唯一
    形态。

### 3.3 风险预告

1. 10/15 日换手预计为月度的 1.5~2 倍（16%→25~32%/月），microcap
   成本拖累 +3~5pp——净超额起评即负，需要 Z1 短周期 IC 增量（域内
   日频 IC 0.07 vs 月度 0.07，理论上无增量优势）来补，大概率闭合；
2. 本实验是"诉求闭合实验"而非"寻找新策略"——无论结果如何都写终章。
