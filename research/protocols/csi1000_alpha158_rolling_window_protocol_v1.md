# CSI1000 全量 Alpha158 滚动窗口重训诊断协议 v1

## 1. 目的与背景

主线 ROADMAP 阶段 2 需要确定信号生产管道所用的价量信号源。此前
（`csi1000_core13_rolling_window_protocol_v1.md`）已确认：

- 滚动重训 + 标签 CSZScoreNorm 修正后，Core13 残余 13 因子在
  2021-2026 全期 IC ≈ 0.008，费后超额为负，不可作为信号源；
- 加市值/行业显式特征对 13 因子几乎无增益（IC 0.0089 vs 0.0084）。

但此前只测了"从 158 个中筛出的 13 个"残余因子，未测**全量 158 因子**
在滚动重训下的表现。存在两种可能：

1. 量价信息本身在 2021 后整体衰减（则全量 158 同样无效，价量信号源
   结论成立，阶段 2 必须另寻信号或如实记录弱信号）；
2. 筛出的 13 个因子恰好丢了仍有信息的成分（则全量 158 滚动可能
   明显更强，阶段 2 信号源 = 全量 158 滚动）。

本协议只回答这一个问题：

```text
全量 Alpha158（158 因子）在滚动重训下，2021-2026 的真实预测力是多少？
```

它是阶段 2 信号源选择的**证据输入**，本身不构成阶段 2 管道实现。

## 2. 信息边界

| 时间区间 | 角色 |
|---|---|
| 2017-11-01 至 2018-12-31 | 数据预热与首个训练窗数据 |
| 2019-01-01 至 2026-07-23 | 滚动训练窗与评估窗 |
| 2026-07-24 以后 | 不读取、不预测 |

与 Core13 滚动协议完全一致：每个交易日的预测只使用该日之前已披露的
因子、市值与行业；模型只由该日前 3 年样本训练。无未来函数、无样本内
选择偏差。

## 3. 固定配置

| 项目 | 固定值 |
|---|---|
| 股票池 | Qlib `csi1000` 每日历史成分（PIT，含退市股） |
| 标签 | `Ref($close,-2)/Ref($close,-1)-1` |
| 特征 | Alpha158 全部 158 个表达式（`Alpha158DL.get_feature_config`，kbar+price+rolling 默认参数） |
| 版本 | 单版本：158 因子（与 Core13 的"加市值/行业"对比已证明无增益，不再重复该对比） |
| 行情源 | `~/.qlib/qlib_data/cn_data_2026` |
| 模型 | `LGBModel` 超参同 B_core13（loss=mse, lr=0.1, colsample=0.9, subsample=0.9, lambda_l1=205.6999, lambda_l2=580.9768, max_depth=8, num_leaves=250, num_threads=20） |
| 标签预处理 | CSZScoreNorm，统计量仅取自训练窗 |
| 滚动规则 | 每 63 交易日重训；训练=前 504 日，验证=前 252 日（早停），预测=后 63 日 |

## 4. 强制报告指标（2021-01-01 至 2026-07-23）

1. 全期日频 IC 均值 / ICIR / RankIC / RankICIR / IC>0 占比；
2. 分年 IC（2021-2026）；
3. `TopkDropout(topk=50, n_drop=5)` 费前/费后（基准与压力成本）年化超额、
   IR、最大超额回撤、日均换手率；
4. 与 Core13 滚动诊断的逐项对比。

## 5. 固定回测设置

与 Core13 滚动协议第 7 节完全一致（TopkDropout topk=50, n_drop=5，
基准 SH000852，基准成本买 0.05% 卖 0.15%，压力成本买 0.10% 卖 0.30%）。

## 7. 结论边界

本实验是阶段 2 信号源选择的证据，不授权部署。运行完成后停止，由用户
依据 Core13 与全量 158 两组证据决定阶段 2 的信号源与管道实现。
