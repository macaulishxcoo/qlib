# 涨停板事件日频策略线 —— 协议 v1

## 1. 状态与问题

状态：`design_frozen_before_data`

**依据（来自隔夜/日内线关闭记录 §2）**：十分位诊断证明「极端近期涨幅」是毒尾，
`id_mom_20` 的 D10 前瞻 5 日年化 **−19.5%**。涨停板是"极端近期涨幅"最纯的形态。
因此问题不是"再找一个排序因子"，而是：

```text
Q. 涨停事件之后，T+1 开盘买入，未来 1/5/10 日的超额收益是多少？
   它能否被**事前可观测**的封板特征（连板数/量比/一字封板）区分开来？
   扣除成本后，可交易子集能否形成正净超额？
```

**为什么这是新方向**：项目 §8 待办第 3 条，此前从未测过。既有 13 条日频线
全部是**截面排序因子**；本条是**事件驱动**，信息结构不同（离散事件 + 条件分档，
而非全截面连续打分）。且隔夜/日内线已证明：在本项目的收益分布里，
**极端尾部的信息远大于截面主体**，事件法正是对准尾部的方法。

## 2. 信息边界与数据（冻结）

| 项 | 固定值 |
|---|---|
| 价格 | Qlib store `cn_data_2026`：`$open $high $low $close $volume` |
| 池 | 沪深主板严格口径：`SH6xx` + `SZ 000/001/002/003`（10% 涨跌幅制度，单一制度无混淆） |
| 样本 | 事件日 2018-01-01 ~ 2026-06-30（2017 供 20 日量比预热） |
| 执行 | 事件日 t 收盘确认 → **t+1 开盘买入** → open(t+1+h) 卖出 |
| 成本 | base 买 0.05% / 卖 0.15%；stress 买 0.10% / 卖 0.30% |

**可交易性（硬约束）**：`buy_ok(t+1)` = open(t+1) 有量、价 ≥ 2 元、
且 `open(t+1)/close(t) − 1 < 9.5%`（涨停开盘买不进）。
**买不进的样本一律剔除，不做事后价格假设。**

## 3. 冻结的事件定义

```text
chg(t)        = close(t)/close(t-1) - 1
封板   lim_close(t) = 0.095 <= chg(t) <= 0.11      # 10% 制度上限，含四舍五入
触板   lim_touch(t) = high(t)/close(t-1) - 1 >= 0.095
炸板   lim_break(t) = lim_touch(t) & ~lim_close(t)
一字板 lim_one(t)   = lim_close(t) & (low(t) >= high(t) - 1e-9)
连板数 k(t)   = 截至 t 连续 lim_close 的天数
量比   vr(t)  = volume(t) / mean(volume(t-20..t-1))
```

`0.095 <= chg <= 0.11` 同时排除次新股上市首日暴涨（不受 10% 限制）。
**注**：封板日必有 `high == close == 涨停价`，故"是否封板"无法用 `close==high` 区分；
真正的强度区分是 **`low == high`（一字，全天未打开）vs `low < high`（盘中打开后回封）**。

## 4. 冻结的标签与条件分档

```text
fwd_h(t) = open(t+1+h)/open(t+1) - 1 ,  h ∈ {1, 5, 10}
excess_h(t) = fwd_h(t) - mean_over_buyable_universe(fwd_h(t))
```

分档（**全部事前可观测，冻结**）：

| 分档变量 | 取值 |
|---|---|
| 事件类 | `封板` / `炸板` |
| 连板数 k | `1`（首板）/ `2` / `>=3` |
| 量比 vr | `<0.5`（缩量）/ `0.5~1.5` / `>1.5`（放量） |
| 一字 | `lim_one` True / False |

方向先验（冻结，用于解读；判定不依赖先验）：
- **H1** 首板 (k=1) 强于 连板 (k≥3)；
- **H2** 缩量封板 (vr<0.5) 强于 放量 (vr>1.5)；
- **H3** 一字板强于盘中回封；
- **H4** 炸板弱于封板。

## 5. 冻结的判定规则

**端点 A（主，事件研究）**：每个分档单元报告
`excess_h` 的**按日聚类**均值与 t 值（同日多事件先取日均，避免截面相关高估显著性）。

**端点 B（次，事件组合）**：每日在所有满足过滤条件的事件上等权建仓、持有 h 日；
有事件则满仓事件、无事件则空仓。报告 base/stress 净收益、换手、回撤。

**判定**：

| 结论 | 条件（**全部满足**） |
|---|---|
| `supported` | ① 存在事前冻结的分档单元，其 `excess_5` 在 **stress 成本后** > 0；② 该单元的按日 t ≥ 2.0；③ 先验 H1~H4 中至少 2 条在数据中得到同向确认；④ **样本前后两半（2018-2021 / 2022-2026）同号** |
| `not_supported` | 否则 |

**条件 ④ 的理由**：隔夜/日内线的教训——单看统计强度会被尾部结构欺骗。
分半同号是本线对"事后挑选"的最低防线。

**禁止**：本线不做阈值扫描、不追加窗口、不调整持有期以改善结果。
分档边界（0.5 / 1.5 / k=2/3 / 9.5%）**全部冻结**。

## 7. 结论边界

1. 只有日线，**无法知道封板时间、封单量、开板次数**——这是涨停研究最关键的信息，
   本线只能用 `low==high`（一字）与量比做粗代理。**这是本线最大的证据缺口**，
   若结果模糊，优先补分钟级数据而非调参。
2. 涨停事件高度时间聚集（牛市多、熊市少），事件组合的仓位利用率随时间剧烈变化，
   **端点 B 的"年化收益"含择时成分，不等于纯 alpha**；故以端点 A 为主判据。
3. `top_list`（龙虎榜）数据本地已有但本线**不使用**，保持零额外数据依赖；
   若本线显示封板特征有区分度，龙虎榜席位数据作为下一步增量。
