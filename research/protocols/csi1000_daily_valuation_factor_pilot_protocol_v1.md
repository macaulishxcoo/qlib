# CSI1000 日度估值因子试点协议 v1

## 1. 本步骤要回答的问题

本试点只回答一个问题：

```text
Tushare 日度估值快照中，是否存在剔除行业和自由流通市值影响后，
仍能预测 CSI1000 中期横截面收益的独立信息？
```

此前 Alpha158/Core13 与换仓速度实验已经表明：继续调整同一批价量因子、
LightGBM 或 `TopkDropout` 参数，不能形成可交易的稳定净超额。因此本试点
开始更换信息源，但仍保持最小范围，不进行自动公式挖掘、模型训练或回测。

本文件只冻结下一项数据与单因子验证设计，**不授权下载数据或执行检验**。
用户审查并明确同意后，才能进入数据补齐步骤。

## 2. 为什么先选日度估值，而不是 Alpha101/191 或遗传规划

- Alpha101、Alpha191、gplearn 和 AlphaGen 的大部分输入仍是 OHLCV，主要解决
  “如何组合价量变量”，不能解决当前已经暴露的“信息源同质化”问题。
- 当前项目已经保存 Tushare `daily_basic`、历史申万行业和自由流通市值，能够
  复用已经验证过的数据清洗与中性化逻辑，接入风险最低。
- 估值指标的经济含义明确，可以预先固定方向，降低无边界搜索带来的多重检验
  与数据挖掘偏差。
- 该试点若失败，只能否定“日度估值快照”这一小类信息，不能否定季度 PIT
  财务质量、成长或预期修正等其他基本面信息。

## 3. 数据性质与边界

### 3.1 数据源

使用 Tushare Pro `daily_basic` 的历史日度快照，以及已有的历史申万一级行业：

| 字段 | 用途 |
|---|---|
| `pe_ttm` | 滚动市盈率，构造盈利收益率 |
| `pb` | 市净率，构造账面市值比 |
| `ps_ttm` | 滚动市销率，构造销售收益率 |
| `dv_ttm` | 滚动股息率 |
| `free_share`、`close` | 构造自由流通市值控制变量 |
| 历史申万一级行业 | 行业中性化控制变量 |

`daily_basic` 是每个交易日收盘后的估值快照，不等同于带公告日期和修订链的
季度财务报表 PIT 数据。本试点只能验证这些日度快照字段，不能把结果表述成
“完整基本面因子有效”。

### 3.2 可用时点

信号日为 `t`，只使用交易日 `t` 收盘后能够取得的 `daily_basic` 字段；最早在
下一交易日 `t+1` 执行。不得把 `t+1` 以后发布或修订的数据回填到 `t`。

下载后必须抽查字段的历史连续性、异常跳变和缺失机制。若无法确认 Tushare
历史估值使用的是当时已披露财务信息，本试点必须标记为数据口径阻塞，不能
用其结果宣称不存在未来信息泄漏。

### 3.3 时间分工

| 区间 | 角色 | 允许用途 |
|---|---|---|
| 2020-01-01 至 2022-12-31 | 因子开发期 | 数据清洗、方向与门槛检验 |
| 2023-01-01 至 2024-12-31 | 固定确认期 | 对已冻结因子做一次确认，不再改公式 |
| 2025-01-01 至 2026-07-23 | 已污染回溯期 | 完全禁用，不计算、不展示、不参与选择 |
| 2026-07-24 以后 | 严格前瞻期 | 仅供以后冻结版本观察 |

项目现有 `daily_basic` 只有 2023 年以后，因此下一项获批动作应先补齐
2020-2022，并与现有 2023-2024 文件做字段、主键和覆盖率核验。不得下载或
读取 2025-2026 文件来补本试点结果。

## 4. 冻结候选因子

只允许以下四个候选，不得看结果后增加变体、窗口或复合权重：

| 因子 | 定义 | 预期方向 | 经济含义 |
|---|---|---|---|
| `EP_TTM` | 当 `abs(pe_ttm) > 1e-6` 时取 `1 / pe_ttm` | 高值预期收益高 | 每单位价格对应的滚动盈利 |
| `BP` | 当 `pb > 0` 时取 `1 / pb`，否则缺失 | 高值预期收益高 | 每单位价格对应的账面净资产 |
| `SP_TTM` | 当 `ps_ttm > 0` 时取 `1 / ps_ttm`，否则缺失 | 高值预期收益高 | 每单位价格对应的滚动营业收入 |
| `DIVIDEND_TTM` | `dv_ttm / 100` | 高值预期收益高 | 最近十二个月现金分红收益率 |

负盈利公司的 `EP_TTM` 保留负号，以表达亏损状态；其极端值由统一的截面
处理约束。不得仅因为其结果较差而事后改成“只保留正 PE”。

`dv_ttm` 空值只有在数据审计能用 Tushare 字段口径确认其代表“过去十二个月
没有现金分红”时才填为 0；若空值同时可能代表数据缺失，则 `DIVIDEND_TTM`
标记为数据口径阻塞，不允许按结果选择填零或保留缺失。

## 5. 截面处理与中性化

每个交易日、每个因子独立执行：

1. 仅保留当日 CSI1000 历史成分股；
2. 将正负无穷转成缺失；
3. 按当日有效截面的 1%/99% 分位缩尾；
4. 做截面标准化；
5. 以如下设计矩阵做 OLS，并把残差作为中性化因子：

```text
intercept + log(free_share * close) + 申万一级行业哑变量
```

原始因子与中性化残差都要报告，但通过判定以中性化残差为准。这样可以区分：

- 因子自身包含的估值信息；
- 只是因为低估值股票集中在某些行业；
- 只是因为低估值股票同时偏向某个市值区间。

每日有效样本少于 500 只或缺少行业/市值控制的数据，不参与当日 IC；不得用
全样本行业或未来市值替代当天控制变量。

## 6. 标签与持有周期

估值是慢变量，主检验不是 1 日收益。固定主标签为从下一交易日收盘开始的
20 个交易日收益：

```text
Ref($close, -21) / Ref($close, -1) - 1
```

只允许额外报告两个预先声明的期限，用于观察期限敏感性，不能替代主结论：

```text
5 日： Ref($close, -6)  / Ref($close, -1) - 1
60 日：Ref($close, -61) / Ref($close, -1) - 1
```

20/60 日标签存在重叠，显著性必须使用 Newey-West/HAC 标准误；20 日主标签
固定 `maxlags=19`。不得把每日重叠样本当成相互独立来夸大 t 值。

## 7. 强制输出的单因子证据

每个因子至少输出：

1. 各年字段覆盖率、有效股票数中位数、缺失率与异常值计数；
2. 开发期、确认期及逐年的原始/中性化日均 Rank IC、ICIR、正 IC 比例；
3. 20 日主标签 Rank IC 的 HAC t 值；
4. 每日五分位组合的 20 日平均收益及 Q5-Q1 差值；
5. 5/20/60 日 Rank IC 期限曲线；
6. 因子排名在 1/5/20 日后的 Spearman 自相关，用于判断合理调仓周期；
7. 四个估值因子之间、以及与 Core13 中性化残差之间的截面相关性；
8. 所有被剔除交易日及原因，保留机器可审计明细。

这一阶段不训练 LightGBM，也不运行 TopkDropout。单因子证据回答的是“是否有
新增信息”，不是“当前策略能赚多少钱”。

## 8. 预先冻结的通过门槛

每个候选必须同时满足以下条件，才标记为 `valuation_candidate`：

1. 2020-2022 与 2023-2024 两个阶段的日度有效截面覆盖率均不低于 70%；
2. 20 日中性化 Rank IC 在开发期不低于 `0.015`，确认期不低于 `0.010`；
3. 2020-2022、2023、2024 三个切片的 20 日中性化 Rank IC 均大于 0；
4. 开发期和确认期的 20 日中性化 Rank IC HAC t 值均不低于 `2.0`；四个
   候选在两个阶段分别做 Benjamini-Hochberg 校正，单侧 FDR 均不得高于 10%；
5. 确认期中性化后 Q5-Q1 的 20 日平均收益大于 0，且五分位均值至少有
   3 个相邻方向正确；
6. 确认期中性化 Rank IC 至少保留同期原始 Rank IC 绝对值的 50%；若原始
   Rank IC 为负则直接失败；
7. 与任一 Core13 中性化残差的每日截面 Spearman 相关绝对值中位数低于
   `0.70`，避免把价量信息重新包装成“新因子”。

门槛只产生候选，不证明可实盘。不得因四个候选均未通过而降低阈值、调整
公式、改标签期限或从 2025-2026 寻找正结果。

## 9. 家族级决策

- 至少一个候选通过：冻结通过因子，下一步另立协议做“Core13 基线 vs
  Core13 + 估值候选”的固定增量模型比较。
- 全部失败：停止日度估值快照路线，下一步优先接入带公告日期的季度 PIT
  财务质量/成长数据；不返回 Alpha158、模型横扫或换仓参数调优。
- 数据口径无法确认：标记 `data_lineage_blocked`，先解决数据时点问题，不计算
  任何有效性结论。
