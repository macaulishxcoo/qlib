# 隔夜/日内收益分解日频因子线 —— 协议 v1

## 1. 状态与问题

状态：`design_frozen_before_data`

**背景与转向**：用户明确指示——目标是一条**真正的日频策略**，而项目既有主线
（五因子价值/质量）是**月频策略**（月频 alpha + 日频执行），不属于本目标。
同时指示：**不再沿既有方向继续**。

**本线要回答的问题**：

```text
Q. 把日频收益分解为「隔夜（close->open）」与「日内（open->close）」两部分后，
   这两个分量各自、以及它们的差异，是否携带未来 1/5/10 日的截面信息？
   若有，扣除真实成本后能否形成可交易的日频多头超额？
```

**为什么这是新方向（不是重复既有 13 条线）**：
既有全部价量因子（Alpha158、主升浪 15 因子、量价电池 7 因子、趋势、波动）
**一律使用 close-to-close 收益**。隔夜与日内分量背后的交易者结构不同
（隔夜跳空 = 消息/散户订单失衡；日内 = 机构流），其信息轴与 close-to-close
动量/反转**不同源**，且本项目从未测过。

**与既有教训的关系（写死）**：项目 §5 教训 1「**IC 正 ≠ 可交易**」
（换手率水平 IC +0.064，top50 组合年化 **−0.49**）。因此本协议**从第一步就同时
报告扣成本组合结果**，不出现"只有 IC 没有净值"的中间结论。

## 2. 信息边界与数据（冻结）

| 项 | 固定值 |
|---|---|
| 价格 | Qlib store `cn_data_2026`：`$open`、`$close`（后复权） |
| 池 | 项目既有母池口径：沪深普通 A 股，排除 `30*` 创业板、`688*` 科创板、`BJ`、B 股、指数 |
| 样本期 | 2018-01-01 ~ 2026-06-30（2016-2017 供 20 日窗口预热） |
| 成本 | 项目既有两档：base 买 0.05% / 卖 0.15%；stress 买 0.10% / 卖 0.30% |
| 执行 | t 日收盘出信号 → **t+1 开盘成交**（涨跌停 ±9.5% 不可成交） |

## 3. 冻结的因子定义

日频分量（t 日收盘即可知）：

```text
on_1(t) = open(t) / close(t-1) - 1          隔夜跳空
id_1(t) = close(t) / open(t) - 1            日内
```

| 因子 | 定义 | 方向先验 |
|---|---|---|
| `on_mom_N` | `sum(on_1, N)`，N ∈ {5, 10, 20} | +（隔夜动量） |
| `id_mom_N` | `sum(id_1, N)`，N ∈ {5, 10, 20} | −（日内反转） |
| `on_id_spread_N` | `on_mom_N - id_mom_N` | + |
| `on_share_N` | `on_mom_N / (|on_mom_N| + |id_mom_N| + 1e-8)` | + |
| `on_vol_20` | `std(on_1, 20)` | −（隔夜彩票性） |
| `id_vol_20` | `std(id_1, 20)` | − |
| `on_id_vol_ratio_20` | `on_vol_20 / id_vol_20` | + |

判定**取绝对值**（方向由数据决定，先验仅用于解读），避免符号猜错误杀。

## 4. 冻结的标签与门槛

标签（遵守 open-to-open 纪律）：

```text
label_h(t) = open(t+1+h) / open(t+1) - 1      h ∈ {1, 5, 10}
```

**两个 endpoint 同时报告，不允许只看一个**：

| endpoint | 定义 |
|---|---|
| A. RankIC | 每因子 × 每 h 的每日截面 Spearman IC；门槛 \|IC\| ≥ 0.02 且 \|ICIR\| ≥ 0.30（日频单因子实用下限） |
| B. **扣成本多头净超额** | 每日按因子取**多头 10%**（约 400 只中取 40 只），**5 日持有 + 缓冲带**（跌出前 20% 才卖），等权；扣 base/stress 成本；超额 = 组合 − 全池等权 |

**判定**：

| 结论 | 条件 |
|---|---|
| `supported` | 存在因子满足 A（\|IC\|≥0.02 且 \|ICIR\|≥0.30，h=5 口径）**且** B 在 **stress 成本**下净超额 ≥ 0，且分子为正 |
| `not_supported` | 否则 |

**为何要求 B 同时成立**：这就是既有教训 1 的直接落实——本线不允许出现
"IC 显著但组合层亏钱"的中间状态被当作进展。

## 5. 缓冲带与持有期的冻结理由

日频策略的成本由换手决定。取 **5 日持有 + 20% 缓冲带**：
- 目标年化单边换手 ≈ 244/5 ≈ 49 次（若无缓冲）；缓冲带预期压到 25–35 次；
- 单边成本 base ≈ 0.10%（买卖各半），故年化成本 ≈ 3%–4%，为 10% 目标留下空间；
- 这些参数**冻结**，不做事后调参。

## 8. 结论边界

1. **只用日线 OHLC**，无法区分集合竞价与连续竞价内部结构；"隔夜"实为
   `close→open`，"日内"实为 `open→close`。
2. **后复权价格**：除权日的隔夜跳空已被复权因子处理，不应产生假跳空；
   但仍需在报告中检查跳空分布是否有异常尖峰（数据健康）。
3. 全池等权超额作为基准，与项目既有 SH000852 口径不同；本线内部自洽，
   **不与既有月频策略数字直接比较**。
