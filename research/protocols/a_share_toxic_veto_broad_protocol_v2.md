# 毒尾否决 + 宽基等权 —— 协议 v2（成本现实性修正）

状态：`design_frozen_before_data`

## 1. 为什么需要 v2

协议 v1 的决策记录 §6 记录了一项**已知的正偏差**：
成本模型只用了比例费率，**未含 5 元最低佣金**，也未做 **100 股整手取整**。

在 50 万本金 / N=150 下：

```text
单笔目标市值 = 500,000 / 150 = 3,333 元
5 元最低佣金 = 3,333 的 0.15%  ->  是模型费率 0.05% 的 3 倍
```

因此 v1 的净收益**系统性偏高**，必须修正后重估。这是 v1 §6 明确留下的待办，
不是新发现的事后调整。

## 2. 冻结的修正内容（只改成本实现，不改任何信号）

| 项 | v1 | v2（冻结） |
|---|---|---|
| 佣金 | 比例 0.05%/0.15% | **max(5 元, 成交额 × 费率)** |
| 整手 | 无 | **100 股向下取整** |
| 现金 | 隐含满仓 | **显式跟踪现金（整手残差 + 卖出所得）** |
| 仓位 | 等权（连续权重） | **等权目标市值，按整手实现** |
| NAV | 不加权日收益均值 | **真实 NAV（持仓股数 × 开盘价 + 现金）** |

费率两档不变：base 买 0.05% / 卖 0.15%（另加印花税已含在卖出费率内）；
stress 买 0.10% / 卖 0.30%。**最低佣金 5 元在两档下均生效。**

## 3. 冻结的对照口径（回应 v1 §8 第 3 条）

v1 用「等权全池」当基准，但该基准在 50 万本金下**不可实施**，会系统性低估策略。
v2 起，**主判据基准改为「同等可实施性的宽基」**：

```text
基准 B0 = 同样 50 万、同样 N=150、同样整手与最低佣金、同样系统抽样，
          但【不施加否决】的组合
基准 B1 = 中证1000 (SH000852)
```

**策略 alpha 的定义 = 策略 − B0**（同口径、同约束、唯一差别是否决）。
`B0 − B1` 单列为 beta，不得计入 alpha。

## 4. 冻结的判定

样本切分不变：**开发 2018-01-01 ~ 2021-12-31；样本外 2022-01-01 ~ 2026-06-30。**

| 结论 | 条件（样本外，全部满足） |
|---|---|
| `supported` | ① alpha（策略 − B0）> 0；② 相对 B1 净超额 ≥ 10pp/年；③ stress 下 ①② 仍成立 |
| `partially_supported` | ①③ 成立但 ② 未达 |
| `not_supported` | alpha ≤ 0 或样本外为负 |

## 5. 结论边界

- 成本修正只会**降低**收益，不会提高。若 v2 下 alpha 转负，则 v1 的正结论被推翻。
- 整手取整会引入现金拖累（预计 5%~15%），该拖累是**真实可实施性成本**，
  不是缺陷；v2 同时报告平均仓位利用率。
- 本协议不调整任何信号参数（否决阈值、N、调仓频率、缓冲带全部沿用 v1）。
