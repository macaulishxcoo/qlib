# Size 3 因子假设检验协议 v1（干净微盘域 + 全市场对照）

## 1. 状态与授权

状态：`frozen_awaiting_run`（2026-09-10）

前置链与先验（本族是九族里与既有结论重叠最深的一族）：
- Size 族 3 个因子：size（-log 总市值）、float_size（-log 流通市值）、
  nl_size（size³~size 截面回归残差，市值非线性成分）；
- **先验声明**：域内（末10%）口径下 size/float_size 的截面区分度已被
  "域构建"本身消费——末10% 内市值的进一步分化对应十分位 D1（+120%）
  与 D1 内部的梯度（Risk 轮曾测市值段）。预期 size/float_size 在域内
  IC 为负（域内更小更强）但这就是"规模 β 的域内残余"，**不构成独立
  alpha**；真正有信息价值的是 **nl_size**（市值非线性残差）——它
  剥离线性市值后捕捉"极小市值相对线性规模关系的偏离"，学术上对应
  壳价值/流动性非线性的非线性溢价；
- 全市场臂：size/float_size 是教科书规模因子（全市场 IC 预期显著为负，
  本项目市值十分位梯度已实测 +120%→+52%），作为"已知结论的对照确认"；
- enhance 融合视角：域内 size 已被"等权全池"的结构性暴露吸收，nl_size
  是唯一可能作为第 8 源进入融合池的候选。

## 2. 因子集与复现（冻结）

| 因子 | 公式 | 实现 |
|---|---|---|
| size | -log(总股本 × 收盘价 / 1e6) | total_share（daily_basic 月末）× 未复权 close |
| float_size | -log(流通股本 × 收盘价 / 1e6) | float_share × 未复权 close |
| nl_size | Residual(size³ ~ size) 截面回归残差 | 月末截面 OLS：size³ 对 size 回归取残差 |

全部用未复权价（与 tushare 口径一致）。

## 3. 双臂与判定（冻结，与前七族同框架）

臂B=干净微盘域、臂A=全市场，月度持有费前，2022-01~2026-08。
门槛同前；**附加预注册**：
- size/float_size 即使过线也标注 `size_beta_residue`（域构建已含规模
  暴露，过线只是域内规模梯度的残余，不进 enhance 池）；
- 只有 **nl_size** 过线才进 enhance 候选池（机制上剥离线性规模，与
  域暴露正交）；
- 与 Z1 |corr|≥0.60 → z1_duplicate；组内归并同前。

出口：nl_size 过线 → 并入 enhance 池（第 8 源）；否则 → `size_axis_
closed`（规模轴的信息已由域构建+等权结构完整捕获，nl_size 无独立
增量）。

## 5. 风险预告（预注册的怀疑）

1. nl_size 的残差在末10% 域内的截面方差可能极小（域内 size 范围窄，
   三次项曲率弱），因子值可能被数值噪音主导——报告截面方差与
   信噪比；
2. 全市场 size/float_size 的负 IC 是"已知的已知"（规模效应确认），
   不算新发现，只作为口径锚；
3. nl_size 若在全市场过线而域内不过线，性质同 yoy_total_asset（跨域
   分化），归入全市场清单。
