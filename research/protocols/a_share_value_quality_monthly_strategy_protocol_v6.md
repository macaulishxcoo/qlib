# 沪深非金融 A 股价值/质量多因子月度策略日频市值网格重验协议 v6

## 1. 状态、问题与授权边界

状态：`design_frozen_before_backtest`

月度市值 PIT（`monthly_free_float_size`）只到 2025-05，导致 v4 策略管道
最晚只能产出 2025-06 名单。已补齐财务四因子到 2026Q2 与日频市值
`daily_basic_pit`（2016-2026，覆盖到 2026-08）。本协议回答：

```text
把调仓网格从"月度市值 PIT（asof=月末、rebalance=次月首日）"改为"日频市值
月末截面（rebalance=月末最后交易日）"，v4 策略（四因子→中性化→ST/容量过滤
→top50 月度换手）是否仍成立——重点是封存期 2023-2025 是否仍为正？

通过后，生产管道改用日频网格，可用期延伸到最新交易日。
```

本协议只授权一次口径重验。口径变更（市值字段、信号日、中性化变量）在运行前
冻结；通过则切换管道，不通过则保持月度网格并如实记录。

## 2. 口径变更（冻结）

| 项 | v4/v3 原口径 | v6 新口径 |
|---|---|---|
| 调仓信号日 | `rebalance_date`=次月首个交易日，`asof_date`=月末 | 信号日=每月最后一个交易日（数据当日可得） |
| 市值来源 | `monthly_free_float_size`（月末 PIT） | `daily_basic_pit` 月末截面 |
| E/P 分母 | `total_mv`（月末 PIT，万元→元） | `total_mv`（日频，万元→元） |
| BM 分母 | `total_mv`（万元） | `total_mv`（万元），`total_share` 用日频值 |
| 股息率 | `dv_ttm`（月度） | `dv_ttm`（日频月末值） |
| 中性化 size | log(自由流通市值) | **log(total_mv)**（日频总市值） |
| 财务四因子 | 月度 PIT 批量 | 同（extended 加载，到 2026Q2） |

其余完全一致：四因子等权百分位秩 composite、ST/退市整理过滤、容量过滤
（单票 200 万 / 20 日均额参与率 ≤5%）、topk=50 等权、月度换手、t+1 开盘价、
涨跌停 9.5%、min_cost 5、基准 SH000852、压力与基准两套成本。

## 3. 时间切分（冻结）

日频市值起点 2016-01，因此重验窗口 2016-01 至 2026-06：

| 阶段 | 区间 | 用途 |
|---|---|---|
| 开发期（部分） | 2016-01 ~ 2019-12 | 与 v3/v4 开发期后段可比 |
| 确认期 | 2020-01 ~ 2022-12 | 与 v3/v4 一致 |
| 封存期 | 2023-01 ~ 2025-06 | **主判定**，与 v3/v4 完全一致 |
| 新覆盖区 | 2025-07 ~ 2026-06 | 观察区（原口径无对应），只报告不判定 |

## 4. 唯一对比

| 版本 | 网格/市值口径 | 角色 |
|---|---|---|
| v3（v4 同源） | 月度 PIT | 基线（封存期 +9.8% / 全期 +10.5%） |
| **v6** | 日频月末 | **本协议唯一检验** |

## 5. 预设判定

- 若 v6 封存期（2023-2025-06）压力成本后年化超额 > 0 且 IR > 0 → 口径
  变更不破坏策略，`dailygrid_viable`，生产管道切换到日频网格；
- 否则 → `dailygrid_not_viable`，保持月度网格，记录口径敏感性。

## 7. 结论边界

新覆盖区（2025-07 后）为观察性报告，不构成验证。日频 `total_mv` 为
不复权口径，与 qlib 后复权行情存在差异；该差异影响市值绝对水平，但不影响
截面排序（同一日所有股票同一复权基准），协议接受此近似并在 methodology 中
记录。
