# 沪深非金融 A 股价值/质量多因子月度策略滑点/容量敏感性协议 v4

## 1. 状态、问题与授权边界

状态：`design_frozen_before_backtest`

承接 v3（`a_share_value_quality_monthly_strategy_protocol_v3.md`）：四因子
中性化 + ST 过滤后，封存期 2023-2025 费后 +9.8%（IR 0.70）、全期 +10.5%
（IR 0.89）。v3 仍残留两个"水分"：

1. **滑点未建模**：成交价 = 开盘价 + 固定费率，未计市价滑点/冲击成本；
2. **单票容量未约束**：等权 top50 单票约 200 万元（1 亿账户），未校验
   单票计划成交额是否超过其日均成交额的参与率上限。

本协议回答：

```text
在保守滑点与单票容量约束下，中性化 + ST 过滤组合的封存期与全期超额是否仍为正？
```

本协议只授权一次**参数敏感性网格回测**，不授权调优选股规则、因子或阈值以
美化结果；网格参数运行前冻结。

## 2. 滑点建模（冻结）

滑点以**单边比例**并入成交成本：

```text
open_cost_eff = open_cost + slippage
close_cost_eff = close_cost + slippage
```

滑点档位（单边，买+卖同值）：

| 档位 | 单边滑点 | 说明 |
|---|---|---|
| S0 | 0.000 | v3 基线（对照） |
| S1 | 0.001 | 温和 |
| S2 | 0.003 | 保守（小盘冲击） |
| S3 | 0.005 | 极端保守 |

## 3. 容量约束（冻结）

对每月调仓日，单票计划成交额 = `ACCOUNT / TOP_K = 200 万元`。以该月
`asof_date` 前 20 个交易日平均成交额 `avg_amount` 计：

```text
单票参与率 = 200万 / avg_amount
若 参与率 > participation 上限 → 该票当月剔除（composite 置 NaN）
```

参与率上限档位：

| 档位 | participation | 对应日均额门槛 |
|---|---|---|
| P0 | 1.00 | 无约束（v3 基线） |
| P1 | 0.10 | 日均额 ≥ 2000 万元 |
| P2 | 0.05 | 日均额 ≥ 4000 万元 |

## 4. 网格与报告

| 维度 | 取值 |
|---|---|
| 滑点 | 0.0, 0.001, 0.003, 0.005 |
| 参与率 | 1.00, 0.10, 0.05 |
| 成本 | 全部用压力成本（买 0.10% + 卖 0.30%）作为基准，再叠加滑点 |

- 3×4 = 12 个格子；每格报告全期与封存期费后年化超额、IR、最大超额回撤、
  日均换手率；
- 输出 12 格敏感性表 `sensitivity_summary.csv`；
- 关键判定格：**S3+P2（滑点 0.5% + 参与率 5%）**——最极端保守条件下
  封存期与全期是否仍为正。

## 5. 与 v3 的固定一致性

- 选股信号：composite → ST/退市过滤 → 行业/市值截面 OLS 残差，与 v3 完全一致；
- topk=50 等权、月度换手、t+1 开盘价、涨跌停 9.5%、最低佣金 5、基准 SH000852、
  区间 2014-01-01 至 2025-06-30；
- 唯一差异：成本按第 2 节叠加滑点，选股按第 3 节施加容量约束。

## 7. 预设判定

- 若 S3+P2 格封存期压力成本后年化超额 > 0 且 IR > 0 → 策略在极端保守
  条件下仍可交易，标记 `viable_under_stress`，进入阶段 2 信号管道；
- 若封存期转负 → 如实记录滑点/容量对 alpha 的侵蚀幅度，评估是否仍值得
  推进，不调优。

## 8. 结论边界

滑点是参数化假设（真实冲击成本需实盘验证）；容量约束假设单票全在开盘价
一次性成交。结果用于判断策略在保守前提下的存活性，不构成实盘保证。
