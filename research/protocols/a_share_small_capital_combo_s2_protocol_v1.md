方向信息（已收口）、趋势状态为系统性暴露（supported 但 ICIR 0.23）。唯一具有
正向选股证据的信号是**价值质量复合**（ep/bm/accruals，月频 40 日中性 RankIC
0.04-0.08，已验证）。本协议回答：

```text
用已验证的组件（质量复合选股 + 两融拥挤剔除 + 趋势状态过滤）组装一个
"集中持仓（top15）+ 低频调仓（月末）"的策略，在小资金约束下扣费后
是否为正超额？两融/趋势过滤层是否提升表现？
```

**定位**：组合可交易性检验（首次组装）。不改变任何前序协议结论；若可行则
构成可执行策略候选，进入实盘准备（阶段 3）或进一步细化（另行协议）。

**授权边界**：只回测本协议冻结的两个版本；不搜索 topk/n_drop/调仓周期/过滤阈值；
不因回测结果修改前序因子定义；不做日频全换仓。

## 2. 信号与过滤（冻结）

### 2.1 选股信号：质量复合（正向，已验证）

| 项 | 冻结值 |
|---|---|
| 因子 | `ep`（profit_dedt TTM/total_mv）、`bm`（bps×share/total_mv）、`accruals`（-(NI_ttm−CFO_ttm)/total_assets），复用价值质量线冻结公式 |
| 组合 | 三因子横截面百分位秩等权平均（与 S1 一致） |
| 日频化 | 财务慢变量按 `available_date <= t` 广播到日频；市值分母用 daily_basic 日频 total_mv |
| 调仓日 | 每月最后一个交易日（`monthly_rebalance_grid`）按当日信号选 top15 |

### 2.2 过滤层（逐调仓日 asof 应用）

| 过滤 | 规则 |
|---|---|
| ST/退市 | `st_status_pit_v1` PIT 区间剔除 |
| 停牌/涨停 | 调仓日无有效价量、涨停信号日（主板 0.095/创业科创 0.195）剔除 |
| 两融拥挤 | `rzye_zscore > 2` 剔除（margin，已验证 IC -0.043） |
| 流动性 | 调仓日前 20 日平均成交额最低 20% 剔除（与价值质量线一致） |

### 2.3 版本（预定义，非搜索）

| 版本 | 内容 |
|---|---|
| **主版** | 质量复合 top15 + 2.2 全部过滤 |
| **对照** | 主版 + 趋势状态过滤（剔除 `TS_UP60=0`，即过去 60 日收益 ≤ 0 的股票） |

两版本冻结对比，回答"趋势状态过滤是否提升"。

## 3. 回测规则（冻结）

| 项 | 冻结值 |
|---|---|
| 持仓 | top15 等权（集中持仓，适配 <50 万） |
| 调仓 | 月末按信号重排（每月一次，低换手）；调仓日 T+1 开盘成交 |
| 基准 | SH000852（CSI1000） |
| 成本 | base（买 0.05%/卖 0.15%）、stress（买 0.10%/卖 0.30%），min_cost 5 元 |
| 窗口 | 2022-01-01 ~ 2026-07-31（与全部前序检验可比） |
| 账户 | 1,000,000（等比例缩放，与 <50 万同构） |

## 4. 报告与验收

- 报告：费前/费后（两套成本）年化超额、IR、最大超额回撤、日均换手率、年化成本损耗；
  分年度；2025-07 后压力段单独报告（价值质量线 v6 该段为负）。
- 验收（对齐 `metrics_judgment_standard.md`）：

| 条件 | 判定 |
|---|---|
| 主版 stress 费后年化超额 > 0 且 IR > 0 | `viable` → 实盘准备候选，进入阶段 3 或细化 |
| 主版 stress 费后 ≤ 0 但 base > 0 | `base_only` → 评估成本敏感性与换手 |
| 主版 base 费后 ≤ 0 | `not_viable` → 归档，组件组装不成立 |
| 对照（含趋势过滤）≥ 主版 | 记录趋势过滤增量；不改变主版判定 |
